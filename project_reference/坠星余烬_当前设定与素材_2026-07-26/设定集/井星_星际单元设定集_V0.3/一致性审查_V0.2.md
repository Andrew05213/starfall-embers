# 2. 已修正问题

## 2.1 维修层人数口径

初稿写为“砾、老栓及3～5名居民”，可能被理解为老栓不计入3～5人，与文案手册的救援容量口径产生偏差。

现改为：

> 砾，以及老栓在内的3～5名砾熟悉的维修居民。

这样同时兼容“交叉梁下还有四个人”的具体对白和3～5名普通居民的动态结果。

## 2.2 留守代价表达不足

初稿只在“留形锚”条目说明需要观察断裂，未在拔核场景中明确写出“必须有人留守”。现已在坠核抽取台区域补充：

> 标准撤离只能稳定三条支路中的一条；最后航路必须由一名现场人员持续校正，不能用自动装置消除留守代价。

# 3. 新增候选内容的边界

以下内容是本册为了让井星成为可独立生产的星际单元而补充，不属于上游冻结事实：

- 芦灯、拂灰、苔罐三名次要居民。
- 沉浆鳗、钉足兽、巢膜虫、囊灯孢群、梁听螨等扩展生态。
- 锚屋、公共炉、冷却井、压力门等常见建筑模块。
- 轨道巢月、壳外采掘环等外围地点细节。

这些新增项均满足三条限制：

1. 不替代砾、简七、照临的主线职能。
2. 不创造额外无代价离星路线。
3. 不扩大拔核救援容量或取消留守牺牲。

# 5. 仍需在下一阶段决定的问题

这些不是矛盾，而是进入区域关卡包和文案包前需要冻结的生产决策：

1. 三名新增居民是否全部进入标准世界池，还是每轮只生成其中1～2人。
2. 新增生物中哪些属于井星常驻基础生态，哪些只在特定世界相位出现。
3. 井星见证的完整取得条件，是否需要“古炼室状态＋坠核状态”双条件，还是允许古炼室独立形成残缺见证。
4. 轨道巢月是否在所有上升兽路线中存在，还是作为世界变体之一。
5. 角色20像素标尺下，砾的大型扳杆和照临的见证匣是否计入碰撞轮廓，或只作为装备层绘制。
