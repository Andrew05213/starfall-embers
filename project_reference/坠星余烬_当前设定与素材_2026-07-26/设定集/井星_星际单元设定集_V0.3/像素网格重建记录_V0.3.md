# 《坠星余烬》井星像素网格重建记录

> 版本：V0.3  
> 输入：V0.2审核通过的AI生成概念图  
> 输出：透明背景、严格网格对齐的正式概念资产

## 1. 继承与变更边界

V0.3不重新设计对象，不改变V0.2已经审核通过的对象比例、画布尺寸、主体位置、轮廓意图与主配色。处理仅用于消除AI生成图中残留的平滑色阶、底板、伪像素和半透明边缘。

- 人物、生物、物品：保留64×64逻辑画布。
- 环境、建筑：保留160×90逻辑画布。
- 人物高度继续以约20原生像素为基准。
- 怪物与物品继续使用与人物一致的像素密度和原有世界比例。
- `assets/source/`保留原始审核图，便于追溯；正式使用`assets/split/`、`assets/native/`和`assets/master/`。

## 2. 重建规则

1. 所有正式精灵按整数像素坐标保存，不执行亚像素移动。
2. 独立精灵的生成底板被转为完全透明背景。
3. 环境图只移除与画布边缘连通的近黑虚空／底板；封闭洞穴、设备阴影和内部黑线保留为场景内容。
4. Alpha通道只允许0与255，不存在半透明抗锯齿。
5. 人物与生物共用16色，物品共用16色，环境共用48色。
6. 调色板映射禁用抖动，避免在轮廓附近制造棋盘噪点。
7. 放大母版只使用整数倍最近邻缩放：人物／生物6倍，物品5倍，环境4倍。

## 3. 输出目录

```text
assets/
├── master/   # 透明背景、整数倍最近邻预览母版
├── native/   # 透明背景原生像素母版
├── split/    # 22个透明独立资产
├── source/   # V0.2审核通过的AI生成源图（只读追溯）
└── tools/
    ├── extract_assets_v02.py
    └── pixel_align_assets_v03.py
```

## 4. 可重复执行

在设定集根目录执行：

```bash
python3 assets/tools/pixel_align_assets_v03.py
```

脚本会先从`assets/source/`中的V0.2审核源图重新生成逻辑拆分图，再重建透明硬边图、生成`native`与`master`母版，并自动校验画布尺寸、透明像素、二值Alpha和非空主体。每次都从保留源图开始，因此可以安全重复执行，不会在已经限色的结果上二次处理。

## 5. 验证结果

- 22/22拆分资产尺寸通过。
- 22/22拆分资产包含透明像素。
- 22/22拆分资产Alpha值严格限定为`0`或`255`。
- 3/3原生母版为RGBA透明PNG。
- 3/3预览母版使用最近邻整数倍放大。
- 原始生成稿未被覆盖。

## 6. 使用约束

- 游戏引擎导入时关闭纹理过滤、MipMap、压缩平滑和子像素采样。
- 摄像机缩放优先使用整数倍；非整数缩放会在运行时重新引入视觉错位。
- 正式动画应直接在本版透明精灵上逐帧绘制，不要从高分辨率源图重新缩小。
- 环境图仍是结构与色板基准，不等同于可直接平铺的最终Tilemap；制作关卡前仍需拆分地块、前景、背景与交互层。
