# 井星星际单元设定集 V0.3

本版本继承V0.2中已经审核通过的比例、轮廓与配色，将全部正式图片重建为透明背景、硬边Alpha、固定调色板的严格网格像素资产。

## 文档

- `井星_星际单元设定集_V0.3.md`：设定正文与三张透明像素概念母版。
- `概念资产生成与拆分记录_V0.2.md`：比例、生成约束、拆分顺序与后续生产边界。
- `一致性审查_V0.2.md`：与冻结基线的核对结果。
- `像素网格重建记录_V0.3.md`：透明化、限色、像素对齐与验证记录。

## 资产

- `assets/master/`：适合直接查看的整数倍最近邻母版。
- `assets/native/`：未放大的透明原生像素母版。
- `assets/split/`：22个透明独立资产。
- `assets/source/`：审核通过的生成源图。
- `assets/tools/`：可重复执行的拆分与像素重建脚本。

## V0.3视觉冻结

- 人物：约19～21像素高。
- 怪物：使用相同像素密度，但允许显著大于人物。
- 物品：按世界实体比例绘制；正式母版不含比例对比人形。
- 环境：160×90像素单格。
- 像素：所有正式资产使用整数坐标、硬边轮廓和二值Alpha；无平滑缩放、无半透明抗锯齿。
- 色板：人物／生物共用16色，物品共用16色，环境共用48色。
