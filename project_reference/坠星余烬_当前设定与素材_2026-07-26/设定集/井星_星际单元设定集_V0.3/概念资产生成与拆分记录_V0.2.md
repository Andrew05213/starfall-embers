# 1. V0.2变更

V0.1的50像素人物比例作废。V0.2统一以**20像素高的常规成年人**作为井星世界尺度尺。

本次变更包括：

1. 三名NPC重新绘制为约19～21像素高。
2. 怪物不受人物尺寸上限约束，按真实体量区分小、中、大型生物。
3. 物品按相对于20像素人物的世界尺寸绘制，不再填满64×64单元格。
4. 审核母版中的灰色人物标尺只用于确认比例，正式物品母版已将其全部移除。
5. 环境概念图继续沿用160×90原生画布。

# 3. 资产目录

```text
assets/
├── master/   # 正文引用的整数倍最近邻预览母版
├── native/   # 未放大的原生像素母版
├── split/    # 22个独立资产
├── source/   # 最终生成与审核源图
└── tools/    # 分隔带识别与拆分脚本
```

正式拆分脚本：`assets/tools/extract_assets_v02.py`

脚本采用“先识别行、再逐行识别列”的方式处理生成母版。这样即使模型生成的上下两行单格宽度略有差异，也不会切掉上升兽翼膜或把相邻对象带入资产。

# 4. 最终生成约束摘要

## 4.1 人物与怪物母版

- 3列×2行，相同64×64逻辑画布。
- 上排人物统一约20像素高，身体宽8～10像素。
- 下排按体量分别绘制上升兽、沉浆鳗和钉足兽。
- 全表共用不超过14色。
- 只允许硬边像素簇、一层阴影和最近邻整数倍预览。
- 禁止抗锯齿、渐变、高清纹理、写实面部和“像素滤镜式插画”。

## 4.2 物品比例母版

- 4列×2行，相同64×64逻辑画布。
- 审核稿曾在每格左侧放置20像素灰色人形，仅用于比较。
- 审核通过后，使用图像编辑只移除灰色人形并补回背景；八项物品的尺寸、位置和像素结构不变。
- 正式母版不含人物标尺。

## 4.3 环境母版

- 2列×4行，每格160×90原生像素。
- 场景优先表达行走面、物质路径、承重结构和坠律方向。
- 环境图是结构与色板基准，不是固定关卡截图。

# 6. 后续生产边界

- 当前图片冻结的是比例、轮廓、主色和材质语言，不是最终动画帧。
- 正式角色仍需制作透明背景、正反朝向、行走、受击、死亡和坠向切换动作。
- 小型物品在世界中可以通过轮廓闪光、轻微运动、声音和交互提示提高可见性，不放大实体。
- 大型生物的攻击距离、身体分段与可破坏区域应从视觉体量推导，不能把整只生物压成一个人物大小的碰撞盒。
- 新增井星资产必须以20像素人物为比例尺，不能在后续批次中逐渐提高角色分辨率。
