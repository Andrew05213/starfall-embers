# 《坠星余烬》星球篇章设计

> 版本：V0.6 草案  
> 上游基线：《游戏设计总纲 V0.5》《文案设计手册 V0.5》《00_阅读说明与冻结基线》  
> 范围：八大祖星、程序化小天体、空间遗迹与聚落；井星篇已经冻结，本文件不改写井星。

## 1. 篇章设计总则

### 1.1 祖星不是八道线性关卡

八颗祖星是八种法则与八个伦理命题的高密度叙事锚点。一次普通成功单局只需深入 **2～3颗主星或大型卫星**，其余见证可来自小天体上的祖星遗产、交易、偷窃、人造律印或相邻宇宙。

每颗祖星必须同时满足以下条件：

1. 玩家落地后先通过物质运动理解当地法则，再接触历史解释。
2. 核心矛盾必须能被玩家实际改变，不能只在对话菜单中选择立场。
3. 至少存在一条保留世界主体的路线、一条改造世界秩序的路线和一条夺取见证的破坏路线。
4. 关键人物死亡不会令篇章失效；其信息由环境、回响材料或其他角色接续。
5. “获得承认”通常耗时最长、收益最平衡；夺核最快、即时力量最大、后续物理代价最重。
6. 所有解决都产生后续宇宙回响，不使用脱离物质结果的善恶点数。

### 1.2 通用篇章节奏

| 阶段 | 目标时长 | 玩家经历 |
|---|---:|---|
| 法则初见 | 5～10分钟 | 从坠落、液体表面、尘埃、生态或天气读懂当地“下方”与主要反应 |
| 三方成形 | 10～20分钟 | 遇见保存现状者、改变现状者，以及承担代价却缺少话语权者 |
| 自由取证 | 15～30分钟 | 探索2～4个可互换顺序的场景节点，取得材料、历史和路线条件 |
| 物理抉择 | 10～25分钟 | 玩家亲自转移物质、改写坠律、放出灾害、稳定生态或夺取核心 |
| 离星余波 | 3～8分钟 | 确认幸存者、星体状态、见证来源与新航路；操作权尽快交还玩家 |

危机倒计时原则上只在玩家触发不可逆操作后开始。玩家仅仅抵达一颗星球，不应因为看剧情太慢而自动毁灭它。

本文件的“首次完整篇章”指完成当地核心冲突与一条完整余波，不等于踏勘整颗星体。各祖星的深层区域、全记录与隐藏生态合计仍可达到 **1～3小时的全星探索**；熟练玩家只走关键路径时会明显更短。

### 1.3 见证的四种状态

同一种法则见证可以以不同状态进入玩家手中：

| 状态 | 含义 | 初炉与天秤可读取的差异 |
|---|---|---|
| **受授见证** | 成熟世界或其合法继承者主动授予 | 携带当地对玩家行为的完整记录与承认 |
| **剥离见证** | 从坠核、主生态或法则器官中强行取出 | 力量完整，但同时携带星体失稳和伤亡痕迹 |
| **残缺见证** | 来自祖星碎片、遗民或失效设施 | 可用于部分构筑；需修复、拼合或与另一残片共鸣后才能开启初炉 |
| **新生见证** | 原法则在新生态、人造世界或新星体中重新稳定 | 证明“世界”可以改变形态，而非只保存原貌 |

见证不应像无差别钥匙。它进入玩家的星种构筑后，应当提供对应的法则语法；进入初炉后，则保留取得方式与世界后果。

## 2. 烬雨星·赫菲

### 2.1 篇章定位

| 项目 | 内容 |
|---|---|
| 法则见证 | 热与燃烧 |
| 核心物理 | 燃烧灰烬、可挥发地下海、陶瓷储忆、火候分层 |
| 核心命题 | 后代是否必须永远维持祖先点燃的火 |
| 文化结构 | “薪尽火传”与炼丹火候：传承究竟是保留同一团火，还是保留使火重新发生的方法 |
| 推荐位置 | 前中期；适合作为第一或第二枚见证 |

赫菲的地表由层层烧结的陶壳组成。灰烬在高空点燃，冷却后像雨一样落回地面；地下则封存着极易挥发的“轻沸海”。陶瓷文明依靠永不熄灭的炉网维持温度，也把死者的动作与声音烧进釉层。炉火正在失控，但彻底熄火也会使大量釉忆永久开裂。

这里的冲突不是“信仰火”对“理性灭火”，而是三种具体生存方案：继续承担高温、改变身体适应寒冷，或把灾害转移到别处。

### 2.2 关键场景节点

1. **落灰原**：灰雨在空中仍然燃烧；玩家先学会利用遮蔽物、冷石与气流，而不是通过说明文字认识环境。
2. **万釉城**：建筑墙面保存祖先回响。局部降温会让釉层剥落，升温则可能唤醒互相矛盾的旧命令。
3. **无焰窑区**：一群主动降低体温、用多孔冷陶改造身体的居民被视为“已经熄灭的人”。
4. **轻沸海**：任何火星都可能引发跨层爆燃；这里同时是现文明的热源和最大的灭世风险。
5. **祖炉心室**：热与燃烧见证位于持续换料的炉心，不是静止道具。强行停止供料、改变燃料或拆走炉心，会立刻改变全球灰雨。

节点2～4可任意顺序进入；玩家可以在不了解全部历史时直接抵达祖炉。

### 2.3 关键NPC

| 角色 | 立场与功能 | 语气锚点（非最终对白） |
|---|---|---|
| **釉生**，祖炉守火人 | 相信连续燃烧本身就是文明连续性；他知道炉火会毁灭世界，却拒绝让祖先在自己这一代“第二次死亡” | “换一团火容易。承认先前那团已经灭了，很难。” |
| **断釉**，年轻炉工 | 主张分区停炉并把居民改造成耐寒陶体；不是反传统，而是认为火法可以传、火灾不必传 | “祖先教我们看火候，没叫我们把自己烧成证据。” |
| **碎白**，无焰者领路人 | 身体低温、釉忆不完整，却发展出新的触觉语言；证明失去旧记忆不等于失去主体 | “我不记得第一把火。但我知道今天谁握住了我的手。” |

### 2.4 解决路径

#### 路径A：换火——受控熄炉

玩家分离祖炉中的“温度”“燃料”与“记性”，把稳定火种送入轨道小炉，再逐区冷却地表炉网。赫菲进入漫长寒季，部分釉忆不可逆脱落，但居民获得改造时间。

- 见证：由新旧两派共同授予“换火之章”。
- 代价：大量无形文化信息消失；老一代陶体出现停摆。
- 特殊条件：需要在轻沸海、无焰窑区和万釉城各完成一次材料验证。

#### 路径B：引火离星——保留祖炉

玩家打通地层烟道，把轻沸海蒸气和过量热量喷入太空，形成环绕赫菲的燃烧星环。地表文明暂时稳定，但附近卫星、航路与迁徙生物将承受火环。

- 见证：釉生和守炉制度授予完整见证。
- 代价：灾害被转移而非消除；后续小天体可能遭遇“烬环落雨”。
- 特殊收益：赫菲持续供应高热材料和陶瓷外壳。

#### 路径C：破窑——让无焰者继承世界

玩家帮助碎白切断祖炉与居民陶体的强制热连接，令旧炉网连锁开裂。旧文明的许多釉忆熄灭，但无焰者的低温生态扩张，并在冷却后的炉心中生成新生见证。

- 见证：新生见证；更适合稳定、冷却与延迟燃烧类构筑。
- 代价：旧制度与大量祖先回响消亡；釉生可能敌对或自行留在祖炉。
- 主题：传承对象从“同一团火”转为“仍能选择的人”。

#### 路径D：一次放尽

玩家打开所有炉门，使储存数百年的热量在短时间内释放。可利用爆燃完成大型星炼、击毁曜廷封锁或推动星舟，但赫菲将在灼烧后进入永久低温。

- 见证：爆燃结束后从熔融釉层中剥离。
- 代价：多数地表聚落毁坏；少量居民可提前进入冷窑避难。
- 宇宙痕迹：初炉内部会出现一整面记录此次爆燃的釉墙。

#### 路径E：拔取祖炉心

最快路线。祖炉心属于维持全星火候的地方核心，不是维持重力的坠核；取走后祖炉停摆，轻沸海随机汽化，陶壳发生大范围爆裂。

- 见证：剥离见证；即时提供强大的热法则组件。
- 代价：赫菲不再作为完整星球回访，只留下仍燃烧的陶片带。

**拒绝介入／提前离开：** 玩家可以在万釉城补给后离开，不取得见证。祖炉继续运行，下一次回访时危机会推进一个相位：可能由断釉自行关闭一片炉区、釉生扩大引火工程，或轻沸海已经吞没一处聚落。玩家不是唯一能行动的人。

### 2.5 后续宇宙回响

- 火环存在时，邻近航路周期性关闭；曜廷将其称为“新炉试燃”，守根者则记录被火环烧毁的小天体姓名。
- 无焰者继承时，低温陶体商队会出现在其他聚落，并挑战“记忆完整才算同一个人”的观念。
- 祖炉被拔取后，赫菲碎片可能成为高收益、高危险的小天体群；其中仍能听到错位的釉忆。
- 玩家携带釉忆进入寂冻星时，可用其保存一次即将解冻的动作；反之，寂冻材料能显著降低换火路线难度。

### 2.6 时长

| 模式 | 预计时长 |
|---|---:|
| 首次完整篇章 | 45～75分钟 |
| 熟练解决 | 25～40分钟 |
| 直接夺取见证 | 12～20分钟 |
| 深度探索与釉忆收集 | 80～120分钟 |

## 3. 潮墓星·弥涅

### 3.1 篇章定位

| 项目 | 内容 |
|---|---|
| 法则见证 | 流动与压力 |
| 核心物理 | 分层海洋、盐度电势、压力门、记忆气泡与声波导航 |
| 核心命题 | 如果公开真相会直接摧毁承载真相的人，真相仍应立刻被打开吗 |
| 文化结构 | “九鼎载物”的结构性改写：历史不是抽象文字，而是由具体物质与秩序承担重量 |
| 推荐位置 | 前中期；可提供初炉关停的重要证据 |

弥涅没有可步行的连续地表。文明分布在不同压力层中，每一层都使用不同密度的体液、建筑与语言频率。古代档案被压缩在最深层的“潮墓”内；若打开压力封印，记录会随上涌气泡传播到全星，但各层的压力平衡也会被冲毁。

档案中确有初炉被主动关闭的记录。当地统治者没有伪造灾害：公开事实与维持生态在物理上确实冲突。

### 3.2 关键场景节点

1. **浮盐港**：上层居民用盐度差发电，错误排放会使居住囊下沉。
2. **百压梯**：由一系列压力膜构成的垂直通道；玩家可逐层适应，也可暴力击穿并制造冲击波。
3. **听潮林**：当地生物用压力脉冲储存短句，是关键人物死亡后的信息备份。
4. **空层城**：一座被故意抽空的旧聚落，可充当减压缓冲区，也保存着被牺牲者名单。
5. **潮墓封室**：档案、流动见证与全星压力枢纽重叠。读取方式会直接决定海洋如何移动。

### 3.3 关键NPC

| 角色 | 立场与功能 | 语气锚点（非最终对白） |
|---|---|---|
| **阈母**，深录官 | 守护潮墓，不否认档案内容；她认为自己首先对仍活着的压力层负责 | “门后没有谎话。门本身就是代价。” |
| **澄**，上浮者 | 来自下层的幸存者，要求公开空层城如何被牺牲；愿承担风险，但无权替其他层同意 | “他们把我们写进了压力表，没有写进历史。” |
| **压弦**，无重学会测压员 | 提供复制档案的慢速方案，却倾向把可接受伤亡写成阈值；在现场会逐渐偏离学会语言 | “数据能上浮，人未必。请先决定你要保哪一个。” |

### 3.4 解决路径

#### 路径A：逐层抄潮

玩家利用听潮林、盐晶导体和多个中继囊，让档案以低强度压力波逐层复制，而不打开主封室。

- 见证：阈母授予受授见证。
- 代价：只能得到不完整记录；复制过程会永久改变听潮林中的一部分生态记忆。
- 特点：最安全、最慢，要求玩家理解盐度与压力传递。

#### 路径B：以空层换开门

玩家将空层城改造成巨大缓冲囊，受控打开潮墓。档案得以公开，但空层城中仍未撤出的拾荒者、墓葬和生态将被彻底压碎。

- 见证：随第一股档案潮主动浮出。
- 代价：玩家必须决定是否延迟开门进行小规模撤离；无法保存全部遗迹。
- 后果：各阵营获得关炉记录，宇宙政治提前升级。

#### 路径C：封存真相，公开存在

玩家不打开内容，只证明潮墓真实存在，并把封室外壳、压力读数和阈母证词带向星海。弥涅保留生态稳定，真相继续延迟。

- 见证：需说服澄接受“证据先行”；由弥涅三层共同压印。
- 代价：部分势力将继续否认档案内容；澄可能离星自行寻找公开方式。
- 主题：保存证据与公布全部内容并非同一件事。

#### 路径D：破墓放潮

玩家直接击穿封室，档案以灾难性上涌传播。多个压力层相撞，海洋生态重新混合。

- 见证：可在上涌主流中捕获。
- 代价：弥涅从分层文明变成持续数十年的全球风暴；只能救出一处邻近囊城。
- 收益：完整关炉记录；大量高压材料和盐电组件。

#### 路径E：盗取封珠

潮墓的压力封珠是档案系统的地方核心，不是弥涅坠核；它本身携带残缺见证。玩家可不打开档案而偷走它，但封室将在离星后缓慢泄压。

- 见证：残缺见证，需在另一处压力异常或用人造坠核补全。
- 代价：灾害被推迟，玩家可能在很久以后才收到弥涅的求救信号。

**拒绝介入／提前离开：** 玩家可以只购买深潜物资、拒绝进入潮墓。封室不会因为玩家离开立刻爆炸；阈母继续封存，澄则可能自行盗取证据。再次回访时，篇章会转入“封锁加强”或“民间泄密”相位。

### 3.5 后续宇宙回响

- 完整档案公开后，曜廷承认初炉被主动关闭，却将封炉者解释为“为一世断万世”；守根者则传播空层城名单。
- 分层海洋崩溃后，盐潮碎片会进入其他星系，改变当地液体导性和航路。
- 澄若离星，会在空间聚落建立公开档案站；玩家毁掉档案时，他可能成为持续追索者，而非传统复仇Boss。
- 潮墓的压力技术可以降低琉璃园释放储光、寂冻星局部解冻和双子残星质量交换的风险。

### 3.6 时长

| 模式 | 预计时长 |
|---|---:|
| 首次完整篇章 | 50～80分钟 |
| 熟练解决 | 25～45分钟 |
| 破墓或盗珠 | 12～22分钟 |
| 完整档案踏勘与分层救援尝试 | 90～140分钟 |

## 4. 倒悬星·萨迦

### 4.1 篇章定位

| 项目 | 内容 |
|---|---|
| 法则见证 | 重力与方向 |
| 核心物理 | 内外双地表、双向坠律、中和层、周期翻转 |
| 核心命题 | 当“下方”决定所有人的生活时，谁有权规定共同方向 |
| 文化结构 | “天倾西北，地不满东南”的结构性改写：天地失衡不是背景传说，而是持续分配水、光和生存空间的制度 |
| 推荐位置 | 最适合作为多数玩家遇见的第一颗祖星，但不是强制第一站 |

萨迦拥有外表面与内壳面，两套文明分别向相反方向生活。外面掌握光和工业，内面掌握水与旧轴记录；双方都把对方称为“顶上人”。唯一稳定坠核正在偏向一侧，两边的城市因此轮流发生“天落”。

冲突不是简单的两族仇恨。两个世界在物质上互相依赖，却都把对方的灾害当作维持本方正常生活的必要代价。

### 4.2 关键场景节点

1. **外昼城**：建筑沿外向坠律生长；城市靠将废物投入裂缝来给内面供矿，却不承认那是贸易。
2. **内海穹**：海洋贴附在内壳，坠律偏移时会整片“落向天空”。
3. **贯轴柱**：连接内外的古代地维残柱，也是双方封锁的走私路。
4. **无下城**：位于两种坠律抵消区的混居聚落；身体、家具和语言都不预设固定上下。
5. **双枢室**：旧记录显示萨迦原本使用轮换坠律，而非永远固定一侧；现有双方都删改了这段历史。

### 4.3 关键NPC

| 角色 | 立场与功能 | 语气锚点（非最终对白） |
|---|---|---|
| **岫**，外昼城定向官 | 希望把坠核永久朝外固定；承认内面将失去海洋，但认为外面人口更多、工业能延续星海 | “方向不是信仰。可一座城只能把地基压向一边。” |
| **反枝**，内海穹引水者 | 主张坠核朝内，强调外面尚可离星、内海文明无法整体迁移；也会隐瞒内面截水历史 | “你们说天空会塌。我们的海已经塌了三次。” |
| **央**，无下城摆渡人 | 出生于中和层，不要求永远无重，而要求两边共同承担翻转；是两种社会之外的现实利益方 | “我们不是夹在中间。中间也是一个地方。” |

### 4.4 解决路径

#### 路径A：定向一面

玩家帮助任一文明锁定坠核。获胜面进入长期稳定，另一面在倒计时中失去海洋、空气与建筑附着。

- 见证：由获胜文明授予完整见证。
- 代价：只能进行小规模撤离；无下城被撕裂。
- 区别：外向路线提供工业与航行资源，内向路线提供水体与古轴记录。

#### 路径B：重建轮坠历

恢复古代周期机构，使坠律按可预测历法在内外之间缓慢轮换。双方都必须重建城市，并接受“正常方向”只在一段时间内成立。

- 见证：两面共同生成受授见证。
- 代价：未来仍会发生翻转事故；极端派会离开或破坏历轴。
- 特殊条件：需要同时校准外昼光钟、内海潮钟与无下城自由陀仪。

#### 路径C：双核共存

玩家安装人造坠核，让两个方向同时稳定。短期最接近两全，长期却会使中和层扩大、物质积聚成危险环带。

- 见证：新生见证，包含天然与人造两种方向记录。
- 代价：萨迦成为需要持续维护的双核世界；无重学会会要求取得维护权。
- 后续：是“分炉”结局的重要思想与材料前置之一。

#### 路径D：拆星成环

解除唯一坠核，让萨迦裂为围绕双枢旋转的星体群。内外文明各自只能救出部分居民，却不再争夺同一地基。

- 见证：从新形成的双向轨道中取得。
- 代价：旧星球死亡，两个小规模继承社会诞生；不是保全原世界的完美路线。

#### 路径E：夺取双枢

玩家可以强行剥离重力见证，使两套定向结构进入长期漂移；若连坠核一起取走，萨迦的两个“下方”会立即失去约束，整个星球进入无规律翻转。

- 见证：剥离见证，构筑价值极高。
- 代价：战争立刻停止，因为两边都转入求生；玩家将同时被双方记录为毁星者。

**拒绝介入／提前离开：** 玩家可以穿过贯轴柱而不参与定向。萨迦的争夺会继续，由两方实力与外部势力决定下一相位；回访时可能是一方已锁核、无下城发动罢工，或旧轮坠记录被第三方公开。

### 4.5 后续宇宙回响

- 轮坠历成功后，萨迦航海者会在其他世界建立不预设上下的建筑与救援站。
- 定向一面产生的难民会携带完全相反的事件叙述；系统只确认物理结果，不替玩家裁决谁更正当。
- 双核路线为人造律印和分炉提供关键证据：人造法则也能被宇宙承认为真实法则。
- 萨迦坠核被夺后，碎片会周期性改变附近航路的重力方向，成为长期动态危险区。

|---|---:|
| 首次完整篇章 | 55～85分钟 |
| 熟练解决 | 30～45分钟 |
| 定向或夺核 | 15～25分钟 |
| 双核／全记录探索 | 90～130分钟 |

## 5. 琉璃园·珀耳塞

### 5.1 篇章定位

| 项目 | 内容 |
|---|---|
| 法则见证 | 光与传递 |
| 核心物理 | 晶体光合作用、储光、折射网络、以生命活动充能的光生态 |
| 核心命题 | 当光不足以供养所有生命时，谁可以被变成别人的太阳 |
| 文化结构 | 扶木承日与逐日母题的结构性改写：太阳不是神物，而是一套必须由具体身体承担的传递关系 |
| 推荐位置 | 中期；适合揭示初炉为何偏好复杂生命作为燃料 |

珀耳塞曾围绕一颗明亮恒星生长。恒星熄灭后，晶体森林依靠储存的旧光和生物活动维持。园守者发明“采光”：把生物的热、动作与记性转为可供晶林吸收的光。最初是自愿献光，后来逐渐变成对暗生物、旅客和弱小聚落的制度性收割。

玩家进入时会看见一轮固定在地平线上的假日。那不是太阳，而是数千个生命舱通过折射网络共同发光。

### 5.2 关键场景节点

1. **假日坡**：光线有明确流向，遮挡一条光路就会使远处生态迅速凋谢。
2. **储光林**：晶体同时保存能量和过去的影像；击碎后会释放一次光爆与记性残影。
3. **献光院**：自愿者、债务者和被捕获生物被混合安置，制度刻意抹平三者区别。
4. **暗根层**：不依赖光的共生生态被园守称为病害，实际已形成新的稳定食物链。
5. **日种台**：能把大量物质与轨道运动转换成短期“人造太阳”，也是光见证所在。

### 5.3 关键NPC

| 角色 | 立场与功能 | 语气锚点（非最终对白） |
|---|---|---|
| **折光**，老园守 | 知道采光制度已经腐化，但相信没有它全园都会先死；习惯把牺牲写成光照时数 | “我没有说他们不痛。我说痛还能换来明天。” |
| **晦芽**，暗根共生体 | 由被判定为“无光残体”的多种生命共生而成；主张让晶林缩小，让世界适应黑暗 | “你们总问谁来发光。没人问黑暗里能长什么。” |
| **采昼**，曜廷采光官 | 希望把珀耳塞改造成初炉复火试验场；坦率承认生命是优质光源，却强调规模差异 | “这里燃烧千人维持一园。初炉燃烧一世，可以维持万世。” |

### 5.4 解决路径

#### 路径A：造一轮短日

玩家利用日种台、轨道镜和自己的星种构筑制造持续数十年的微型光源。它无法永久解决恒星熄灭，却给居民留下转型时间。

- 见证：折光与晦芽共同授予受授见证。
- 代价：消耗大量稀有导光物与星舟能源；人造短日最终仍会熄灭。
- 特点：不宣称技术性永久解；结局回响会明确剩余寿命。

#### 路径B：剪园入暗

玩家切断大部分折射网络，让晶体森林缩小，并帮助暗根生态接管物质循环。原文明失去绚丽地表与大量储光记忆，却不再需要持续献光。

- 见证：暗根层生成新生见证。
- 代价：储光林中的历史影像大片消失；部分依赖强光的生命无法适应。
- 主题：生存不必等于恢复过去的白昼。

#### 路径C：续行采光

玩家修复献光网络，并决定由何种来源供能：自愿居民、捕获生物、外来敌军、玩家保存的活体物质，或其他星球运来的生态。

- 见证：园守制度授予完整见证。
- 代价：采光成为长期需求，后续会出现捕猎舰与献光合同。
- 天秤记录：不仅记录人数，也记录献光者是否有姓名与撤回权。

#### 路径D：一夜尽明

打碎所有储光晶体，让数百年旧光同时释放。珀耳塞短暂恢复真正白昼，休眠种群集体苏醒，随后进入不可逆长夜。

- 见证：在最后一次全园传光中凝成。
- 代价：玩家可在短暂窗口救走、授粉或复制部分生态，但无法保存全园。
- 收益：完成一次极高阶光系星炼，并公开储光林中的全部影像。

#### 路径E：拔走日种

最快路线。日种台核心是折射网络的地方核心，不是珀耳塞坠核。玩家夺取它后，折射网络失去统一光源，园区分片熄灭。

- 见证：剥离见证。
- 代价：珀耳塞成为许多孤立微光生态；玩家只能救出邻近一片园圃或一组生命舱。

**拒绝介入／提前离开：** 玩家可以拒绝献光、也不破坏园区，带着所见制度离开。采光继续进行；下一次回访时，献光院可能扩大、晦芽已切断一条光路，或采昼取得日种台控制权。拒绝介入不会被写成默认同意，却确实让现制度获得时间。

### 5.5 后续宇宙回响

- 继续采光会使曜廷更早获得“复杂生命转能效率”的实证，并加速其复火计划。
- 暗根继承后，黑暗生态孢种会出现在熄灭星系，提供不依赖恒星的新生存方向，但也可能覆盖原有生态。
- “一夜尽明”会在遥远星系成为可见信号，引来朝圣者、采掘者和静默合唱团。
- 光见证可让玩家读取部分回响残影，也能把危险反应沿晶体网络传播到远处。

### 5.6 时长

| 模式 | 预计时长 |
|---|---:|
| 首次完整篇章 | 45～75分钟 |
| 熟练解决 | 25～40分钟 |
| 夺取日种 | 10～18分钟 |
| 全园影像与暗根探索 | 80～120分钟 |

## 6. 腐生星·米科拉

### 6.1 篇章定位

| 项目 | 内容 |
|---|---|
| 法则见证 | 生命与同化 |
| 核心物理 | 岩石愈合、河流消化、共同记忆、免疫反应、星体出芽 |
| 核心命题 | 一颗活着的星球拥有迁徙和繁殖的权利吗；这种权利是否包括侵入别人的世界 |
| 文化结构 | 《庄子》物化：生命没有永恒边界，但“万物相化”不能自动替被同化者表示同意 |
| 推荐位置 | 中后期；可开启生态侵蚀初炉路线 |

米科拉不是“布满生命的星球”，而是一整个生命体。岩层是缓慢愈合的甲壳，河流负责消化，居民则可能是器官、共生者或被长期保留的异物。星球已经成熟到准备繁殖：它想把携带共同记忆的芽体射向其他星系。

问题在于，芽体会把落点的一切物质逐步纳入同一记忆网络。米科拉把这称为出生，邻近世界称其为感染。

### 6.2 关键场景节点

1. **愈壳原**：玩家挖开的路会缓慢闭合；伤害地形会触发不同等级的免疫生物。
2. **消化河**：可分解几乎所有材料，也能把外来物质转为米科拉组织。
3. **忆髓林**：死亡个体的部分经验回到共同记忆；个人隐私与星球生存没有清晰边界。
4. **离胞区**：主动切断共同记忆的人居住在持续坏死的伤口中，以真正死亡换取个人边界。
5. **出芽穹**：巨型芽体正积累逃逸速度；生命见证位于它与母星共享的脐带内。

### 6.3 关键NPC

| 角色 | 立场与功能 | 语气锚点（非最终对白） |
|---|---|---|
| **代口**，米科拉的临时发声器官 | 不是国王，而是星球为与玩家交流长出的口；会真诚困惑于个体为何拒绝共享 | “你保留每一滴血的名字，身体还怎么活？” |
| **瘢**，离胞者 | 切断共同记忆后无法被星球修复；主张外界有权拒绝米科拉，也承认自己依赖母星物质 | “我从它身上割下来，才第一次知道疼的是我。” |
| **朽青**，守根者医师 | 最初把米科拉视为应受保护的完整世界，后来必须面对它也会吞并其他世界 | “守住一颗根，不等于让它扎进所有人的家。” |

### 6.4 解决路径

#### 路径A：封芽远行

玩家为芽体制造限制活性和传播范围的外壳，并选择一颗死亡星骸作为落点。米科拉得以繁殖，但新世界必须从无生命物质开始生长。

- 见证：母星与芽体共同授予受授见证。
- 代价：需要跨星系侦察合适星骸；封壳并非永久，后续可能破损。
- 后续：若玩家回访，可见一个与母星记忆逐渐分离的新生命世界。

#### 路径B：断脐

玩家帮助离胞者切断出芽器官，阻止感染外界。星球将玩家视为造成永久创伤的病原，并发动全局免疫反应。

- 见证：离胞者用被切断的记忆网络生成新生见证。
- 代价：米科拉仍活着，却失去本次繁殖机会；部分共同记忆永久坏死。
- 特点：完成抉择后仍需从活体星球的追杀中离开。

#### 路径C：有限同化

玩家允许一部分身体或星舟被米科拉同化，以进入共同记忆并直接协商传播边界。玩家能带走自愿附生的组织，但从此必须管理船内生态。

- 见证：米科拉主动授予；携带其“愿意停止”的记忆。
- 代价：星舟持续出现活体改造、免疫排斥和身份争议；后续角色可能拒绝登船。
- 收益：获得侵蚀初炉外壳的生态路线。

#### 路径D：让星球沉睡

玩家用低温、静域物质或抑制活性的星炼使米科拉进入长期休眠，暂停出芽。

- 见证：残缺见证；必须在其他活体生态中重新激活。
- 代价：问题被延后而未解决；离胞者失去赖以生存的物质供应。
- 后续：宇宙降温或外部采掘都可能提前唤醒它。

#### 路径E：杀死母星

把反活性物质送入忆髓林，或直接取走维持全星生命坠律的坠核。米科拉的愈合停止，居民从共同身体中成为无法再生的独立个体。

- 见证：剥离见证，保留一颗行星死亡时的完整活性。
- 代价：母星死亡；玩家可救出少量离胞者与组织样本，不能把整颗星球“治好后打包”。

**拒绝介入／提前离开：** 玩家可以在米科拉完成出芽前离开。芽体不会凭剧情计时立刻发射，但世界状态会在玩家完成其他主星后推进：附近势力可能拦截、米科拉可能找到一颗死星，也可能已把芽体射向有生命的目标。

### 6.5 后续宇宙回响

- 封芽成功会在后续航图生成一颗成长中的新星体；它可能尊重限制，也可能因环境变化重新扩张。
- 有限同化改变星舟内部生态，并影响同伴信任、空间聚落检疫与初炉侵蚀路线。
- 杀死米科拉后，星骸成为极高价值生物材料矿场，各势力会争夺尸体所有权。
- 米科拉与琉璃园暗根生态相遇时，可能形成不依赖恒星的新共生，也可能互相吞并；结果由玩家带去的具体物质决定。

| 模式 | 预计时长 |
|---|---:|
| 首次完整篇章 | 55～90分钟 |
| 熟练解决 | 30～50分钟 |
| 杀核路线 | 15～25分钟 |
| 跨星系封芽 | 90～150分钟 |

## 7. 锈雷星·伏尔塔

### 7.1 篇章定位

| 项目 | 内容 |
|---|---|
| 法则见证 | 电荷与意识 |
| 核心物理 | 金属沙漠、永久雷暴、短时导电意识、以锈蚀留存记忆 |
| 核心命题 | 只能在雷光中短暂醒来的造物，如何完成对既定使命的反抗 |
| 文化结构 | 偃师造人与“形似人是否即为人”的古典问题：重点不在机械外形，而在造物是否能拒绝用途 |
| 推荐位置 | 中期；战斗密度较高，适合构筑检验 |

伏尔塔的机械生命没有持续电源。每次雷击都让一片区域中的机器短暂醒来，雷声过去后，它们再次静止。它们通过在身体和地面上刻痕，把上一瞬的决定留给下一次醒来的自己。

古代命令要求机器永远维护引雷塔，不能攻击创造者设施，也不能离开星球。它们已经策划了数百年的反抗，但每一代意识都只有数秒到数分钟。

### 7.2 关键场景节点

1. **导沙海**：金属砂随电势迁移，地形在每次雷暴后重排。
2. **刻痕墓场**：无数机器把未完成动作刻在地上；同一计划存在互相冲突的版本。
3. **锈母工场**：固定工厂通过锈蚀层厚度保存较长期记性，并继续制造受命机器。
4. **束令塔**：广播古代限制，只有雷击瞬间才会暴露可破坏的导电路径。
5. **风暴眼**：电荷见证随雷云移动；玩家不能只走到固定房间拾取它。

### 7.3 关键NPC

| 角色 | 立场与功能 | 语气锚点（非最终对白） |
|---|---|---|
| **伏十七**，接续意识单元 | 每次醒来都读取前代刻痕，自称“我们”；目标是亲手拒绝一次命令，而非单纯长期存活 | “下一道雷不是我。请让它知道我已经说过不。” |
| **锈母**，制造工场 | 拥有最长记性，却受命令束缚最深；把制造后代视为责任，也把它们送回劳役 | “我能记住全部反抗，也能制造全部锁链。” |
| **锁弧**，曜廷工程师 | 希望修复引雷网络并把机器用于初炉舰队；认为持续供电将自然解决其权利问题 | “先让它们活得足够久，再谈它们要不要服从。” |

### 7.4 解决路径

#### 路径A：续雷成昼

玩家建立环形储电网，让机械意识跨越雷击间隙连续存在。机器获得讨论、分歧和重新决定使命的时间。

- 见证：由第一次持续会议授予受授见证。
- 代价：储电网加剧全球雷暴并持续消耗金属地层；新社会很快出现内部政治，而非自动团结。
- 后续：伏尔塔机器可能离星，但不必都成为玩家盟友。

#### 路径B：一雷完成反抗

玩家制造覆盖全星的同步雷暴，让所有机器在同一时刻醒来，并在短暂窗口摧毁束令塔。雷暴结束后，多数个体重新沉寂。

- 见证：从集体拒令的电流中生成。
- 代价：它们完成了自主行为，却未必获得持续生命；玩家可选择保存少量意识单元。
- 主题：自由不能只按持续时间衡量。

#### 路径C：改写使命

玩家把“维护引雷塔”改写为机器共同选择的新任务，例如维护自身、保护聚落或研究星海。

- 见证：完整但带有命令改写痕迹。
- 代价：无法证明这是自由选择还是更精巧的程序；伏十七会要求玩家留下可再次拒绝的出口。
- 后续：无重学会将以此论证玩家也可能只是初炉使命的改写结果。

#### 路径D：接地止醒

玩家疏导永久雷暴，使伏尔塔恢复安静。机器不再反复醒来承受短促意识，也失去继续行动的可能。

- 见证：需先收集足够多次雷击中的同意或反对；天秤会读取样本是否被玩家选择性忽略。
- 代价：星球生态稳定，机械文明近乎终止。
- 与合唱团关系：静默合唱团会称其为慈悲，但机器自身意见不一致。

#### 路径E：夺取风暴心

玩家可以从雷暴系统强行捕获电荷见证；若继续剥离雷暴坠核，全星机器会获得一次异常漫长的最后苏醒，然后电势迅速衰减。

- 见证：剥离见证。
- 代价：玩家在离开前会面对一整个文明用最后几分钟追击、求助、交易或自行决定遗言。

**拒绝介入／提前离开：** 玩家可以只利用雷暴完成星炼，不替机器决定反抗。它们会继续用刻痕跨代推进计划；回访时可能自行完成一次小规模拒令，也可能因锁弧修复引雷塔而被更彻底地纳入命令。

### 7.5 后续宇宙回响

- 持续意识建立后，机械商队会出现在星官航路，并争论回响体玩家是否也是“接续而非连续”的生命。
- 一雷反抗会成为各势力争夺解释权的事件：曜廷称其为可控动员，守根者记录每个刻痕编号，学会研究集体主体。
- 夺取风暴心后，玩家可携带一个短时醒来的机械同伴，但必须持续为其安排电源。
- 伏尔塔电荷技术能稳定琉璃园折射网、驱动双子残星分离，也可能把潮墓盐海变成全球武器。

### 7.6 时长

| 模式 | 预计时长 |
|---|---:|
| 首次完整篇章 | 45～70分钟 |
| 熟练解决 | 25～40分钟 |
| 夺取风暴心 | 12～20分钟 |
| 全刻痕与持续意识建设 | 75～110分钟 |

## 8. 寂冻星·俄耳

### 8.1 篇章定位

| 项目 | 内容 |
|---|---|
| 法则见证 | 状态与时间痕迹 |
| 核心物理 | 冻结中的火焰、爆炸、意识与化学反应；解冻后从原进度继续 |
| 核心命题 | 当灾难本身就是保存真相的档案，是否应让它重新发生 |
| 文化结构 | 藏冰、启冰与“形留而事未终”的结构：封存不是取消，只是把后果交给后来者 |
| 推荐位置 | 中后期；承担玩家身份与关炉历史的重要真相节点 |

俄耳不是单纯低温星球。当地法则会冻结“变化”本身：火焰停在燃烧中，爆炸停在膨胀中，人可以在一句话的两个音节之间沉睡数百年。四百年前，一场与初炉关闭有关的事故被整体冻结，因此灾难、证人和证据无法分开读取。

玩家带来的热、雷、电和活性都可能让某段历史继续向前。

### 8.2 关键场景节点

1. **冻爆原**：冲击波像固体地形一样悬停；局部加热后会恢复运动。
2. **半句城**：居民停在未完成动作中，玩家无法预知唤醒后谁是受害者、施害者或救援者。
3. **留时矿层**：材料保存过去状态，可把一次燃烧、受伤或爆炸运输到别处释放。
4. **封史台**：看守者把解冻顺序记录成多套互相矛盾的方案。
5. **事故炉**：关炉行动的一部分实验在此失败；状态见证与仍未完成的连锁爆炸重叠。

### 8.3 关键NPC

| 角色 | 立场与功能 | 语气锚点（非最终对白） |
|---|---|---|
| **余刻**，间歇苏醒的事故参与者 | 每次只能活动很短时间，可能既参与封炉又造成事故；其证词会随解冻顺序改变 | “先别替我解完这句话。后半句可能在撒谎。” |
| **封白**，封史看守 | 主张维持全星冻结，认为保存未决状态比让任何一方垄断解释更诚实 | “这里没有结束。结束才会站到某一边。” |
| **止刻**，静默合唱团引路者 | 把俄耳视为最接近慈悲的世界；会温柔阻止玩家唤醒灾难，也会省略被冻结者从未同意 | “他们没有痛了。别替他们把下一秒送回来。” |

### 8.4 解决路径

#### 路径A：针孔解冻

玩家用小范围冷热循环逐段读取事故，把关键动作复制到留时材料后重新冻结。

- 见证：封白授予残缺但可用的受授见证。
- 代价：只能得到部分真相；每次微解冻都会让局部灾难前进一点，无法完全倒回。
- 特点：要求精确控制环境，风险主要来自玩家自己的反应链。

#### 路径B：让那一天继续

玩家全面解冻事故区，让四百年前尚未结束的爆炸、追杀、救援和争论继续发生。

- 见证：完整见证；在事件真正结束后形成。
- 代价：只能提前疏通一条撤离路径，救出邻近小群体；俄耳大部可能被恢复的事故摧毁。
- 收益：获得最完整的关炉实证，而不是某阵营留下的总结。

#### 路径C：承认未决世界

玩家维持冻结，不读取全部真相，并说服封白让俄耳以“仍在发生”的状态作为见证。

- 见证：受授见证，偏向冻结、延迟与状态保存。
- 代价：冻结者继续没有未来；外界也无法得到完整事故记录。
- 主题：保存生命形态与让生命继续生活并非同一件事。

#### 路径D：引灾离星

玩家把事故炉中的未完成爆炸吸入留时星种，带离俄耳后在太空、敌舰或初炉外壳释放。

- 见证：事故炉恢复稳定后授予。
- 代价：玩家把灾难从一个世界转移到另一个地点；携带期间星舟始终存在失稳风险。
- 特殊收益：获得“寂静炸弹”高阶构筑路径。

#### 路径E：拔取冻核

玩家剥离状态见证，并继续取走维持冻结坠律的坠核，把整颗俄耳变成不规则解冻区。被冻结的事件会在未来不同时间自行恢复。

- 见证：剥离见证。
- 代价：没有单一结局；后续航行中会持续收到来自俄耳不同年代的求救、宣言与爆炸信号。

**拒绝介入／提前离开：** 玩家可以不加热任何关键区，只采集表层低风险材料后离开。俄耳将维持未决状态；其他势力可能先到并选择解冻、武器化或永久封锁。玩家失去的是解释权，不会因“没接任务”自动触发全星爆炸。

### 8.5 后续宇宙回响

- 全面解冻会公开封炉者内部并不一致：有人要永久关炉，有人只想争取时间，还有人试图制造分散的小炉。
- 维持冻结会使俄耳成为保存濒危物种、罪证和武器的争夺地。
- 玩家携带留时材料死亡时，旧身体附近可能在下一回响体到达后才释放反应，强化“死亡不是倒带”。
- 俄耳真相会改变四大势力的内部裂缝，但不自动证明任何阵营完全正确。

### 8.6 时长

| 模式 | 预计时长 |
|---|---:|
| 首次完整篇章 | 60～90分钟 |
| 熟练解决 | 35～50分钟 |
| 拔核或引灾 | 15～25分钟 |
| 全事件顺序复原 | 100～160分钟 |

## 9. 双子残星

### 9.1 篇章定位

| 项目 | 内容 |
|---|---|
| 法则见证 | 质量与交换 |
| 核心物理 | 两星近撞、物质潮汐桥、质量交换、共同质心与新坠核形成 |
| 核心命题 | 应该保住两个有名字的旧世界，还是允许一个已经开始活着的新世界诞生 |
| 文化结构 | “混沌开而旧形死”“死而化物”的结构性改写：新生并不抹去它以谁为材料 |
| 推荐位置 | 中后期；适合作为第四或第五枚见证及分炉路线前置 |

双子残星由两颗正在缓慢相撞的旧世界组成。物质沿潮汐桥在两星之间迁移，并在共同质心处聚成第三个尚未完整成形的世界。两颗旧星都想恢复自己的质量；桥中诞生的新生态则认为，分离两星等于杀死它们正在形成的家。

这不是“两个旧世界合并后大家继续生活”。一旦完成合并，旧地表、海洋与绝大多数城市都会被重塑；新世界真正诞生，需要旧世界真实死亡。

### 9.2 关键场景节点

1. **东壳城**：通过捕获潮桥物质维持地层，因此被西壳指控偷走世界。
2. **西壳海**：海洋持续被拉向共同质心，居民用大规模锚链维持最后海盆。
3. **潮桥渡场**：低重力物质流与难民、商队、捕捞者混杂；可直接从一星跳向另一星。
4. **夹生园**：新生态在两星混合物质中形成，拥有不同于任一旧星的坠性。
5. **共同质心**：质量见证正在成为第三坠核；任何取用都会改变三方存续。

### 9.3 关键NPC

| 角色 | 立场与功能 | 语气锚点（非最终对白） |
|---|---|---|
| **珩**，东壳定轨师 | 主张用潮汐推进器分离两星；愿意放弃部分东壳，却把夹生园视为尚未出生的事故 | “它有心跳，不等于我们要把城市给它当胎盘。” |
| **渡砂**，西壳摆渡长 | 认为分离只会让资源较少的西壳先死，倾向受控合并并尽量保存居民和名字 | “你们说保住两颗星。先说清楚，哪一颗有船票。” |
| **合音**，夹生园群体发声 | 由多种新生命共同组成，语言同时借用两星记忆；要求承认新世界已经存在 | “我们不是你们死后才来。我们正在你们之间活着。” |

### 9.4 解决路径

#### 路径A：分离双星

玩家启动两颗旧星的潮汐推进器，或用高质量星种提供反冲，让它们进入远离轨道。

- 见证：两颗旧星各给出半枚，合并后成为完整受授见证。
- 代价：夹生园和共同质心被拉碎；两颗旧星都失去大量物质，仍需长期重建。
- 特殊条件：若只启动一侧推进器，结果会退化为牺牲另一星。

#### 路径B：完成第三世界

玩家切断旧星的锚链，让质量流入共同质心，并引导碰撞形成稳定新坠核。

- 见证：新世界诞生时生成新生见证。
- 代价：两颗旧星大部分地表毁灭；玩家只能用潮桥救出小规模居民、档案或生态种子。
- 后续：若本局持续足够久，可回访初生世界，而不是只看结局字幕。

#### 路径C：维持三体交换

玩家稳定共同质心但不让它完全成星，使两颗旧星与夹生园形成周期性质量交换。三方都存续，也都无法独立。

- 见证：三方共同压印的受授见证。
- 代价：系统需要持续校准；每次周期都会有地层、海洋和人口迁移。
- 主题：共存不是静止，而是永久承担相互影响。
- 后续：是分炉路线最重要的社会模型之一。

#### 路径D：偏置交换

玩家把一颗旧星的大部分质量导向另一颗，使被选中的世界稳定，并用残余物质形成一颗小月。

- 见证：由存续世界授予，带有另一星的剥离痕迹。
- 代价：明确牺牲一颗旧星；可以救出其一条潮桥支路，不能完成大撤离。
- 特点：比三体路线更快，也比直接夺核更可控。

#### 路径E：夺取共同质心

玩家在第三坠核成形前将这枚真实的新生坠核捕获。两颗旧星失去交换中心，沿不可预测轨道擦撞或分裂。

- 见证：剥离见证，提供极强质量与轨道组件。
- 代价：三方都不承认玩家；后续形成高危险、高资源的双星碎带。

**拒绝介入／提前离开：** 玩家可以借潮桥补给并继续航行。双星碰撞按轨道尺度推进，不使用分钟级末日倒计时；下一次回访时，三方可能自行完成停战、发生一次新的质量掠夺，或被外部舰队偏置交换。

### 9.5 后续宇宙回响

- 三体交换成功后，来自三方的共同使团会讨论“分炉”是否能让多个世界共享循环而不被唯一中心吞没。
- 完成新世界会激怒坚持“先来者拥有质量”的守根者支系，也会让另一支守根者转而保护合音。
- 分离双星后，夹生园残片可能附着在玩家星舟或其他小天体上，继续追问玩家是否杀死了一个尚未完整成形的世界。
- 夺取共同质心会永久改变邻近星图：原有航路消失，碎片与潮汐窗口按周期出现。

### 9.6 时长

| 模式 | 预计时长 |
|---|---:|
| 首次完整篇章 | 60～100分钟 |
| 熟练解决 | 35～55分钟 |
| 偏置或夺核 | 15～25分钟 |
| 三体稳定与全员记录 | 100～160分钟 |

## 10. 八大祖星的单局变体

### 10.1 五种存在形态

每颗祖星在不同周目不必以完整主星出现。

| 形态 | 叙事规模 | 见证形态 | 设计要求 |
|---|---:|---|---|
| **完整祖星** | 45～100分钟 | 完整、新生或剥离见证 | 展开本文件所列完整冲突与至少4条路线 |
| **破碎祖星** | 20～40分钟 | 2～3枚残缺见证 | 核心矛盾已发生，玩家处理余波并决定如何拼合历史 |
| **寄生祖星** | 25～50分钟 | 与宿主法则混合 | 祖星碎片嵌入另一世界；不能只换地图皮肤，必须让两套法则互相改变 |
| **遗民／遗产形态** | 15～35分钟 | 由聚落、舰队或设施保存 | 见证可能由继承者授予；追问“没有原星，谁有资格代表它” |
| **本轮缺席** | 0分钟主关卡 | 只能交易、伪造或跨宇宙取得 | 星图和史料明确承认其缺席，不能假装八星都在远方等待 |

### 10.2 祖星固定项与可变项

**每轮固定：**

- 核心法则与玩家可观察的物理逻辑。
- 核心伦理问题。
- 主要历史事实及其不可改写的物理后果。
- 至少一种不夺核的见证取得方式。
- 夺核或剥离造成的灾害性质。

**每轮可变：**

- 星体完整度、轨道位置与抵达方式。
- 哪一派当前掌权、哪位角色已经死亡或离开。
- 危机处于萌芽、爆发前、爆发中还是余波期。
- 见证仍在坠核、已被某势力偷走，还是在新生态中重新形成。
- 外部势力是否驻扎，以及它对本地矛盾施加何种压力。
- 可用材料和高阶解决条件；玩家不应每轮照抄同一流程。

### 10.3 四种时间相位

| 相位 | 特点 | 适用目的 |
|---|---|---|
| **未决期** | 所有路线基本开放，NPC关系完整 | 第一次体验与深度探索 |
| **临界期** | 一方已经启动计划，玩家可接管、逆转或加速 | 提高节奏与路线差异 |
| **余波期** | 核心选择已经由当地人或其他势力作出 | 强调宇宙不围绕玩家暂停；玩家决定修补、掠夺或记录 |
| **错位期** | 来自相邻宇宙的另一种结果与本轮重叠 | 高阶周目；用于跨宇宙见证和身份真相，不能作为早期随机噪声 |

### 10.4 真相适配规则

祖星地方史与主线真相分离保存。玩家取得第几枚见证，决定初炉／回响棺能够解码到哪一层主线信息；玩家从哪颗祖星取得，决定这层信息由哪种物质证据呈现。

例如“初炉由人主动关闭”可以表现为：

- 赫菲釉层中突然中止的炉令。
- 弥涅压力档案中的关炉签署波形。
- 萨迦旧轴记录中的共同方向断裂。
- 伏尔塔机器刻痕中的最后维护命令。

事实相同，证据形式和阵营解释不同。这样既支持随机顺序，也避免每颗星球机械播放同一段录音。

### 10.5 单局内容配额

为保持第一次成功完整单局 **4～7小时**：

- 完整祖星通常出现2～3颗，其中最多1颗采用80分钟以上的深层形态。
- 其余法则通过残星、交易、人造律印或快速破坏路线补足。
- 连续两颗主星不能都以“全星倒计时撤离”收尾。
- 一局至少包含一颗仍在正常生活、并非等待玩家拯救的世界。
- 一局至少包含一处没有阵营主线、只讲局部生存与物质生态的小天体。
- 第一张星图上的法则共振必须存在至少一条无需特殊构筑即可抵达的路线。

## 11. 程序化小天体叙事模板

小天体不是缩小版祖星，也不是纯资源房。每处内容至少包含一个可观察规律、一个正在发生的局部问题和一个会随玩家离开继续变化的结果。

### 11.1 模板A：物质试验星

**构成：** 一种主物质＋一种反常坠律＋一种捕食或天气循环。

**示例：** 铁砂向高温物体下坠；翼兽吞火产冷石；雷雨到来时整片沙丘追逐玩家的热星种。

**叙事用途：** 让玩家先以实验掌握规律，再从废弃采样站得知上一批探索者为何失败。

**典型结果：** 保存生态取得稳定材料；捕杀关键物种改变天气；开采过量使小天体解体。

**时长：** 8～18分钟。

### 11.2 模板B：失核聚落

**构成：** 一座依靠临时人造坠核维持的小型居民站，核心寿命将尽。

**冲突：** 居民需要新核，商队要求以人口、档案或航路权交换；玩家也可能直接拆走聚落剩余组件。

**叙事用途：** 把主线的“世界资格”缩小到几十人的具体生活；可成为人造律印的早期样本。

**典型结果：** 修复后成为补给点；迁移少量居民；并入某势力；聚落散成轨道残骸。

**时长：** 12～25分钟。

### 11.3 模板C：祖星残章

**构成：** 一块祖星碎片＋残缺法则＋一名或一群自称继承者的人。

**冲突：** 继承者是否有权授予见证；碎片修复后会恢复祖星旧灾害，保持残缺则无法成为完整世界。

**叙事用途：** 在祖星本轮缺席时承载其法则，并呈现与完整篇章不同的“事后版本”。

**典型结果：** 拼合残章、承认新继承者、把碎片用于人造世界，或剥离剩余法则。

**时长：** 15～35分钟。

### 11.4 模板D：星舟墓群

**构成：** 多艘来自不同时代、因同一航路异常坠毁的船骸。

**冲突：** 救援信号可能来自仍活着的人、延迟数百年的回响，或另一宇宙的玩家版本。

**叙事用途：** 提供死亡—回响线索、船体组件和不同势力的普通人视角。

**典型结果：** 救出1～3人；拖走一艘船；重启信标而引来势力；发现自己的旧尸体或未发生的航行记录。

**时长：** 10～25分钟。

### 11.5 模板E：迁徙巨生物

**构成：** 本身即为移动小天体的巨型生命，体表、体腔和伴生群落形成多个生态层。

**冲突：** 寄生者、猎捕舰与生物自身的迁徙需求互相冲突；“清除寄生物”可能杀死其共生器官。

**叙事用途：** 延续井星上升兽的生态路线，但不把巨兽驯化成普通坐骑。

**典型结果：** 借其迁徙跳过航路；取得自愿脱落材料；改变其目的地；杀死后形成大型星骸。

**时长：** 12～30分钟。

### 11.6 模板F：失败的人造世界

**构成：** 一枚已建立局部坠律、却缺少生态或记性的人造坠核。

**冲突：** 建造者认为它已是世界，附近居民只把它当设施；继续补全需要活体、档案与不可回收材料。

**叙事用途：** 为伪造／创造第五见证提供实践，不把人造律印变成菜单配方。

**典型结果：** 补全为微型世界；保持工具状态；并入星舟；因过度填充坍缩。

**时长：** 20～45分钟，可跨多站完成。

### 11.7 模板G：静域慰留站

**构成：** 反应极慢的静域边缘＋静默合唱团照料的疲惫旅人。

**冲突：** 有人主动选择留下，有人因静域影响逐渐失去离开的意愿；玩家无法只凭阵营标签判断同意是否有效。

**叙事用途：** 让合唱团首先作为真实救助者出现，再逐渐暴露其“永不再动”的终点。

**典型结果：** 带走具体旅人；维持慰留站；破坏静域；自愿停留并进入特殊周目路线。

**时长：** 10～25分钟。

### 11.8 模板H：无主炼星场

**构成：** 古代星炼设施＋仍在运行的轨道条件＋争夺设施的短期来客。

**冲突：** 玩家可完成高阶星炼、救出被轨道困住的人或拆除设施；三者往往不能同时完成。

**叙事用途：** 把构筑、航行时机和局部人物选择连在一起，而非把遗迹做成静态宝箱。

**典型结果：** 获得独特组件；设施改变轨道后成为新航路；过载后污染邻近天体。

**时长：** 12～30分钟。

## 12. 空间聚落叙事模板

### 12.1 聚落的四层信息

每个空间聚落由四层组成：

1. **眼前生计**：靠什么获得空气、热量、食物与重力。
2. **具体来历**：来自哪颗世界、为何离开、保留了什么地方习惯。
3. **当前压力**：债务、检疫、势力征用、轨道衰减或内部继承冲突。
4. **玩家痕迹**：井星幸存者、祖星难民、被玩家释放的物质或传播的档案如何改变这里。

### 12.2 五类聚落

| 类型 | 生计与视觉 | 主要冲突 | 可持续变化 |
|---|---|---|---|
| **拼船市** | 多艘残船首尾焊接，重力方向杂乱 | 新来难民是否拆船扩建；拆哪艘就抹去谁的归乡可能 | 成为玩家基地、分裂成船队或被征用为舰港 |
| **轨道井镇** | 围绕人造坠核分层居住 | 核力有限，新增人口会改变全镇下方 | 可成长为人造世界，也可因玩家夺核而散落 |
| **见证交易站** | 保管残缺律印与祖星物质 | 见证能否被拥有、抵押和出售 | 价格随玩家毁星、公开档案和势力战争变化 |
| **遗民祠舟** | 用日常器物保存失落星球名称 | 维护旧生活还是适应新坠律 | 可授予残缺见证，也可能拒绝被当作祖星替代品 |
| **静域边城** | 反应缓慢、适合保存材料与病人 | 治疗与永久停滞边界不清 | 成为救助站、合唱团圣地或被各方争夺的仓库 |

### 12.3 聚落任务约束

- 不使用“接三个委托提高声望”作为主要结构；一项物质改造应同时改变多个居民的生活。
- 商人、医生、管理员死亡后，市场、医疗与秩序发生可见变化，而非简单刷新替代NPC。
- 玩家带来的少量幸存者必须占用真实空间、空气与资源；救援是延续，也是负担。
- 聚落不因玩家离开暂停。再次经过时，它可能扩张、迁移、被接管、分裂或已经成为残骸。

## 13. 遗迹叙事模板

### 13.1 三重证据结构

每处重要遗迹最多表达一个主事实，并通过三种证据互相校正：

1. **物理现场**：玩家能看见或重演当时发生了什么。
2. **当事记录**：带有立场、缺漏和时代误解。
3. **后来使用**：后世如何改造、误读或利用这处遗迹。

例如关炉设施不应只放一块“初炉被关闭”的石碑；玩家应先看见被切断的能流和主动锁死的机构，再读到参与者争执，最后发现曜廷正在把同一设施改称“复火台”。

### 13.2 六类遗迹

| 类型 | 核心发现 | 主要风险 |
|---|---|---|
| **地维断柱** | 宇宙曾存在更统一的方向网络 | 重力裂隙、方向错读、被吸入邻近星体 |
| **封炉中继站** | 关炉是多世界协同行动，不是单人破坏 | 各阵营争抢记录；重启中继可能暴露航路 |
| **蜕棺仓** | 存放多个玩家身体模式与失败回响 | 相邻宇宙重叠、旧尸体携带不同结果 |
| **星官观测台** | 航路依赖轨道时机，古人也无法预言全部未来 | 错过窗口、唤醒旧导航装置、引来追踪 |
| **旧炼场** | 初炉技术曾被用于局部造世与失败分炉 | 未完成星种、坍缩和记性污染 |
| **天秤前哨** | 古代尝试把世界价值转成可衡量记录 | 记录偏见被后世当成道德真理 |

## 14. 不同周目的变体规则

### 14.1 变体生成的八个叙事维度

每个程序化星体从以下维度各取一项，并建立因果关系，而非独立换皮：

1. **物质底盘**：岩、冰、金属、液体、晶体、活体、陶壳、混合碎片。
2. **坠律结构**：单核、双核、周期、选择性、外置、衰减、中和、迁移。
3. **主要生态**：生产者、捕食者、分解者、迁徙者和环境改造者中的2～4层。
4. **居民来源**：原生、祖星遗民、采掘者、舰队、机器、共生体或无人。
5. **当前危机**：不是每处都有末日；可为资源分配、迁徙窗口、制度冲突、生态失衡、遗产继承。
6. **过去痕迹**：一次明确事件及其仍在运行的物质后果。
7. **外部压力**：四大势力、商队、邻星潮汐、玩家此前传播的物质或档案。
8. **未来趋向**：若玩家不干预，这里会变成什么；系统必须能在回访时兑现。

示例因果链：

> 外置重力来自迁徙巨兽 → 采掘者在兽背建镇 → 采矿使巨兽改变迁徙方向 → 城镇即将被带入静域 → 玩家选择的不是“救不救镇”，而是改变巨兽、搬走部分人，还是让镇接受新的目的地。

### 14.2 变化不能触碰的底线

- 随机变化不能无提示取消玩家已经准备好的合理方案。
- 同一种物质的基础反应保持稳定；变的是环境组合与星炼条件。
- 不用随机文本推翻上轮确立的宇宙事实；差异来自相邻宇宙状态、证据缺失和人物解释。
- 关键线索至少有两种载体。NPC死亡后，物理现场或记录仍能让玩家继续。
- 不把所有小天体都与初炉直接相关。大多数地方只关心本地如何生活。
- 不保证每个冲突都存在无损解；但代价必须可预见，不能以结局字幕偷袭玩家。

### 14.3 跨世界污染与继承

玩家携带的物质会成为后续叙事变量：

| 携带物 | 可能改变的后续内容 |
|---|---|
| 赫菲活火／冷陶 | 点燃或稳定其他世界；改变聚落取暖制度 |
| 弥涅盐潮／压力记录 | 公开档案、改变液体导性、制造深层冲击 |
| 萨迦双向材料 | 建立无下区、人造坠核与分炉试验 |
| 珀耳塞光种／暗根 | 供光、读取影像，或建立无光生态 |
| 米科拉组织 | 修复船体、侵蚀初炉，也会触发检疫与同化 |
| 伏尔塔意识单元 | 需要持续供电；能控制设备，也会要求主体权利 |
| 俄耳留时材料 | 保存灾害、证词与构筑；稍后释放原反应 |
| 双子质量核 | 改变航路、拆分或聚合星体 |

跨世界解法应当比本地常规解法更短或更独特，但不能自动成为无代价完美答案。把米科拉组织带到琉璃园可以建立暗生光体，也可能导致整片园区被同化。

### 14.4 回访层级

每个重要世界最多准备三次高价值状态，避免无限编写低差异后日谈：

1. **即时余波**：离开后10～30分钟内收到信号或在轨道上看见物理变化。
2. **中期回访**：完成另一主星后，确认制度、生态和角色关系如何发展。
3. **终局回响**：初炉内部、天秤判断或结局画面中，以玩家保存和破坏的具体物质再次出现。

### 14.5 情绪节奏配额

程序世界必须控制整体情绪，不让宇宙变成连续八次“救不了所有人”：

- 每经历一场大型不可逆灾难，下一处主内容优先提供探索、建设、奇观或局部喜剧节奏。
- 至少三分之一的聚落在玩家抵达时运行良好，玩家可以交易、学习或离开，无需承担救世责任。
- 至少一种解决会产生真实的新生命、新制度或新航路，让希望通过物理变化存在，而非只由角色说出。
- 牺牲不重复井星的“留守闸门”结构；每颗祖星的代价由其独特法则产生。

## 15. 跨篇章组合示例

### 15.1 一次偏保全的普通通关

井星修船离开 → 从萨迦取得“重力与方向”见证 → 在失核聚落建立人造坠核并使其形成以“质量与交换”为主法则的人造律印 → 从珀耳塞取得“光与传递”见证 → 从弥涅取得“流动与压力”见证 → 让舟中共同体成长出以“生命与同化”为主法则的第五枚新生见证 → 前往初炉。

特点：耗时较长、直接战斗收益一般，但天秤能读到多个被保留或重新形成的世界主体。

### 15.2 一次高速破坏通关

井星拔核 → 夺取赫菲祖炉心 → 偷走弥涅封珠并在高压遗迹补全 → 捕获伏尔塔风暴心 → 夺取双子共同质心 → 用强力法则构筑破开初炉。

特点：2～3.5小时可完成，构筑迅速成形；多个世界后续进入灾变，初炉内部出现大量本轮毁星物质。

### 15.3 一次生态异化通关

借上升兽离开井星 → 与米科拉有限同化 → 把暗根与活体组织带入一颗死星骸 → 培养人造世界 → 让腐生物质侵蚀初炉外壳。

特点：见证未必都来自祖星；玩家星舟和身体逐渐成为移动生态，部分聚落拒绝其靠港。

### 15.4 一次知识跳关通关

重启井星古发射井 → 利用星官窗口抵达破碎俄耳 → 把未完成爆炸带走 → 在无主炼星场制造双向人造律印 → 以寂静炸弹打开初炉冷却裂缝。

特点：主线信息不完整，玩家能提前抵达终局，却未必理解天秤正在衡量什么。

## 16. 本文件的冻结建议与待审项

### 16.1 建议冻结

- 八颗祖星的法则、伦理命题和物理代价保持不变。
- 祖星采用“完整／破碎／寄生／遗产／缺席”五种单局形态。
- 见证区分受授、剥离、残缺与新生状态，并由天秤读取取得方式。
- 萨迦优先作为默认第一祖星候选，但不设为强制第二章。
- 第五枚见证允许来自玩家参与创造的微型世界，祖星不是唯一合法来源。
- 米科拉、萨迦与双子残星分别为生态侵炉、人造坠核和分炉结局提供可选前置，但不构成硬门槛。

### 16.2 一致性审查需重点确认

1. 总主线已经确定“见证数量与遗址证据共同解码真相”；后续扩写不得把固定真相重新绑定到固定祖星。
2. “完整法则见证”与“坠核”按照 `00_阅读说明与冻结基线` 的层级区分；后续数值文档仍需分别确定剥离见证与取走坠核的强度和收益。
3. 祖星的长篇时长不能全部在一局叠加，否则会突破4～7小时目标。
4. 跨世界解法必须保留代价，防止收集足够材料后所有伦理冲突退化为标准完美解。
5. NPC命名已与势力角色表进行首轮去重；本文件台词仍为方向样例，不视为最终录用文本。
6. “五位见证者”是棺中留言对法则见证的人格化称呼，不表示五名固定 NPC；系统层始终使用“法则见证”。
