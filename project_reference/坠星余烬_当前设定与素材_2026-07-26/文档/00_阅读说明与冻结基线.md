# 3. 项目核心句

> **宇宙中的一切都是物质；每一粒物质都在下坠、反应，并记住自己曾经成为过什么。**

> **离开井底。寻找五位见证者。把自己的心带到初炉。**

> **玩家不是替宇宙寻找标准答案，而是让每个答案留下可触摸的代价。**

# 4. V0.5 冻结基线

## 4.1 世界规则

- 世界由可模拟的“律尘”组成。
- 律尘具有坠、热、流、导、活、记六种倾向。
- 重力不是全宇宙统一背景；成熟星体依靠坠核维持自己的坠律与“下方”。
- 物质可以改变身份，但不会因为剧情需要凭空消失。
- 物理事实只有一套；不同阵营可以用不同名字解释它。

## 4.2 初炉

- 所有已知世界围绕熄灭的黑色恒星“初炉”运行。
- 初炉曾吞解旧世界、洗去记性，并铸造新恒星与世界种子。
- 初炉在四百多年前被有意识地关闭。
- 重燃初炉确实可以让宇宙重新产生世界。
- 最适合作为燃料的不是死石，而是结构复杂、记忆丰富的现存世界。
- 初炉不能被简化为邪神、失控机器或单纯自然灾害。

## 4.3 玩家

- 玩家从井星的回响棺醒来，没有可靠身份记录。
- 棺中留下玩家自己的声音：“带五位见证者回家。初炉仍在等你。”
- 玩家是初炉尚未完成的最后一枚丹胎，也是初炉的“遗失器官”。
- 玩家死亡后并非原身体复活，而是以相邻宇宙中的同源版本为模板再次醒来。
- 不确认灵魂是否转移；叙事只确认形、记性与行为的继承。

### 回响棺的两级连续性

- **近邻接续：**若仍有与玩家连接的可用回响棺，棺会在高度相似的近邻分支中唤醒同源回响体，并同步死亡前的局部高记性历史。因此旧身体仍在死亡地点，NPC、星体破坏与任务后果也能延续；同一关系链中的 NPC 可以记得玩家死亡后的第二具身体。玩家体验上仍属本轮接续，哲学上却不能证明还是同一宇宙或同一主体。
- **整局终止与新周目：**当回响链断裂、玩家失去所有可用棺，或本轮抵达终局后，下一局落入差异更大的相邻分支。基础规律相同，星体、人物与历史细节可以变化；上一局的结局不会被回滚。
- 回响棺究竟是在本地生成身体、转移近邻模板，还是让两种过程重合，保持未知。以上只冻结玩家能观察到的行为规则。
- 普通生命理论上也能使用与自身兼容的回响棺，但设备稀少、身体模式不通用、连续性不保证。玩家的丹胎结构具有异常高的跨棺兼容性，因此不能把所有死亡角色常规“复原”。

## 4.4 主线与见证

- 明面主线只规定结果，不规定路线。
- 常规进入初炉需要五枚法则见证，但见证不限定来自五颗固定祖星。
- 见证可以通过获得承认、夺取坠核、偷窃交易、人造律印或跨宇宙带回取得。
- 八颗祖星是高密度叙事锚点，不是八道固定关卡。
- 一轮普通通关只深入二至三颗主星或大型卫星。

### 坠核与法则见证的层级

- **坠核**是维持整颗星体坠律与局部法则的物理核心；**法则见证**是成熟世界长期运行后形成的可读取法则结构与记性证明。二者相关，但不是同一件物品。
- 世界可以主动授出见证而不失去坠核；这是非破坏路线成立的基础。
- 玩家也可以从坠核、主生态或法则器官中强行剥离见证。此举会造成局部或长期失稳，但不必然等同取走整颗坠核。
- 若玩家连同坠核一起取走，便同时获得见证与高价值核心资源；星体将发生灾难性坠律解体。终局必须分别记录“取得见证”与“夺走坠核”。
- 见证可以作为高阶法则组件接入构筑或用于共振，但不能替代引核，常规使用也不把它消耗成普通弹药。

| 层级 | 作用 | 与其他层级的边界 |
|---|---|---|
| 坠核 | 维持整颗成熟星体的坠律 | 取走会造成整星灾难；不是星种引核 |
| 法则见证 | 证明某类稳定世界法则曾长期存在 | 可以被授予或剥离；不是维持星体的唯一核心 |
| 地方核心 | 维持祖炉、雷暴、档案、生态器官等局部系统 | 可承载或孕育见证，但不必等于坠核 |
| 人造坠核 | 为无核天体或聚落建立真实新坠律 | 属于世界工程；稳定后才可能孕育人造律印 |
| 人造律印 | 人工世界通过资格条件后形成的法则见证 | 是“人造来源的见证”，不是人造坠核本体 |
| 引核 | 星种内部产生微型引力的组件 | 只服务星种构筑，不得简称坠核 |

### 五见证的计数规则

- 常规开炉要求**五个有效见证主体提供五种不同的主法则类别**。既需要“五个世界的证词”，也需要“五种法则”；两种说法缺一不可。
- 八类基本见证仍为：热与燃烧、流动与压力、重力与方向、光与传递、生命与同化、电荷与意识、状态与时间痕迹、质量与交换。
- 同类见证可以增加证词权重、补全历史或改变天秤判断，但不能重复占用常规开炉的类别名额。
- 井星见证归入“重力与方向”。因此，若玩家后来取得萨迦见证，两者都保留证词，却通常只占一个开炉类别。
- 舟中共同体、人造世界与玩家自身不能凭“身份特殊”成为第九类法则。它们必须让某一项尚缺的基本法则长期稳定为主法则，才能作为该类别的一枚人造律印；混合结构一次也只计一个类别。
- 全八见证路线要求八类基本法则分别到场；复合见证不能一物替代多类。
- 棺中留言所说的“五位见证者”是对法则见证的古老人格化表达，不表示五名固定 NPC；系统与教学统一使用“法则见证”。

## 4.5 四大势力

| 势力 | 冻结立场 | 必须保留的合理性与缺陷 |
|---|---|---|
| 曜廷 | 重启初炉 | 真的能恢复宇宙循环；接受现存世界成为燃料 |
| 守根者 | 维护每颗世界的独立生存权 | 能阻止献祭；没有解决宇宙降温的完整方案 |
| 无重学会 | 研究坠核并延迟选择 | 掌握大量真实知识；想让玩家成为新的法则中心 |
| 静默合唱团 | 终止初炉与一切循环 | 能看见延续造成的痛苦；最终也会终止一切生命 |

任何势力都不得被写成唯一真相持有者，也不得整体退化为脸谱反派。

## 4.6 井星篇

- 井星篇已经闭合，后续只做生产化修订，不重写结构。
- 离星共有四条完整路线：修复旧船、借上升兽、拔取坠核、重启古发射井。
- 拔核后执行 11 分 40 秒世界时间的崩塌；玩家只能完成小规模救援，必须有人留守维持最后的下方。
- 四条路线的自然同行者分别倾向于砾、简七、由救援状态决定、照临，但不是强制锁定。
- 第一张开放星图提供法则共振、稳定信标、低温残迹与无标记方向，系统文本为“航行条件恢复。指定目标：无。”

## 4.7 结局

- 重燃初炉
- 永恒静默
- 成为新太阳
- 分炉
- 横向坠落
- 不作选择

不存在官方指定的无代价“真结局”。隐藏内容可以扩展理解与路径，但不能抹去选择的真实代价。

# 5. 本版新增冻结项

以下内容从本轮起作为后续篇章的共同结构使用：

1. **五枚见证首先是五个世界的证词，其次才是开启初炉的权限。**
2. **主线真相按有效见证数量和关键遗址共同推进，不绑定固定祖星顺序。**
3. **前四枚见证让玩家理解“世界可能是什么”；第五枚见证允许玩家决定“什么有资格被称为世界”。**
4. **第五枚见证可以来自天然世界，也可以来自玩家长期维持的飞船聚落、人造世界或玩家自身。**
5. **小规模救援不是失败版拯救世界。被带走的少数生命、物种、材料与名字，可以共同成长为新的见证主体。**
6. **玩家自己的留言来自上一位曾抵达抉择边缘、却拒绝替所有世界作决定的丹胎。**
7. **初炉内部会以实际物质和状态重现本轮被保存、转化与毁灭的世界，不用抽象善恶值代替。**

# 6. 时间轴基线

| 时期 | 已知事实 | 保留的不确定性 |
|---|---|---|
| 太初 | 清者升而为光，浊者坠而成星；初炉开始循环旧世与新生 | 初炉是自然形成、被制造，还是两者兼有 |
| 多轮炉世 | 初炉吞解衰亡世界并铸造新星海 | 过去究竟发生过多少轮宇宙 |
| 封炉前期 | 可用死星减少，复杂活世界成为更高效燃料 | 初炉是否曾尝试主动回避有名世界 |
| 四百多年前 | 多个文明共同折断公共天柱、关闭初炉 | 谁首先提出封炉、谁在最后时刻背叛或妥协 |
| 大静默 | 世界依靠各自坠核维持，宇宙持续降温 | 剩余时间无法被精确统一估算 |
| 前代丹胎 | 一位与玩家同源的存在接近初炉，留下回响信息 | 他是否真正进入初炉、为何最终退回 |
| 本轮井星 | 玩家醒来并以四种路径之一离星 | 井星、角色与携带物由玩家行为决定 |
| 开放星海 | 玩家取得见证，卷入四大势力争夺 | 星球顺序、存亡状态、见证来源全部可变 |
| 初炉终局 | 玩家进入初炉并决定循环方式 | 没有唯一正史结局 |

# 7. 文案共同规则

1. **事实只有一套，名字至少有三套。**
2. 系统与教学使用现代、唯一、稳定的术语。
3. 古称必须晚于玩家对事实的第一次可操作理解。
4. 紧急文本先写后果与时间，再写氛围。
5. 核心信息至少通过机制、环境、语言三条路径传达。
6. NPC 不负责念设定集；其话语必须同时暴露处境、欲望或立场。
7. 古代铭文可以准确记录现象，但不能成为作者全知广播。
8. 不使用“神秘力量”“远古能量”“天选之人”等无法验证的偷懒表达。
9. 不把五行写成五色伤害，不把著名神话人物直接改名为角色或 Boss。
10. 中国文化基础进入宇宙结构、变化模型、地理生态和语言习惯，不堆砌屋檐、龙纹与古风对白。

# 8. 仍待验证，不在本版强行锁死

- 八枚见证全部收集后，初炉是否拥有可称为“人格”的连续意识。
- 前代丹胎拒绝选择的具体原因，以及他是否仍以某种形式存在。
- 分炉结局需要满足的最小世界、关系与物质条件。
- 飞船聚落成为第五位见证者时，是否必须有幸存者自愿承认共同身份。
- 天秤是初炉的一部分、封炉者留下的程序，还是历代世界共同形成的记性结构。
- 哪一颗祖星最适合作为新玩家常规抵达的第一枚见证；当前优先验证倒悬星，但不固定生成顺序。

# 9. 设计验收问题

任何新增篇章至少回答以下问题：

1. 玩家不读文本，能否从物理后果看懂冲突的一半？
2. 玩家能否拒绝当地人给出的所有标准方案，自己制造第三条路？
3. 最快路线是否真的更快，同时留下可追踪的世界后果？
4. 重要 NPC 死亡后，关键事实是否仍有环境或系统备份？
5. 见证是否证明了一个世界的独特存在，而不是普通钥匙掉落？
6. 本篇提出的问题是否与其他祖星不同？
7. 任何“牺牲”是否具体到名字、物质、地点与后续，而不是数字减一？
8. 本篇是否给至少两大势力留下合理解释，而非替玩家公布答案？
