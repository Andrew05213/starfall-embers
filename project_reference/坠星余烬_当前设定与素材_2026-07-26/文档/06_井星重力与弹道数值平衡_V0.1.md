# 《坠星余烬》井星重力与弹道数值平衡补丁

> 版本：V0.1  
> 适用对象：PR #4 `agent/combat-gate1` 当前 Gate 1 原型  
> 目标：井星基础移动不失去手感；常规“斥核＋跳跃＋推进”组合不能逃逸；高速幼种弹道保持可读；拖尾粒子显著慢于弹体。

## 1. 当前源码基线

### 井星与重力

| 参数 | 当前值 | 位置 |
|---|---:|---|
| 井星半径 | 10000 px | `game/scenes/combat_lab.tscn` |
| 表面重力 | 135 px/s² | `game/scenes/combat_lab.tscn` |
| 星外重力 | 与距离平方成反比 | `game/scripts/simulation/material_world.gd` |

星外重力：

\[
g(r)=g_s\left(\frac{R}{r}\right)^2
\]

表面逃逸速度：

\[
v_e=\sqrt{2g_sR}
\]

当前 `R=10000`、`g_s=135`，所以 `v_e≈1643 px/s`。

### 拖尾粒子

当前纵向继承为 `projectile_velocity × 0.075`，再减去 18～25 px/s 的后向速度并加入 5 px/s 横向扰动。以 1200 px/s 弹速计算，粒子实际纵向速度只有约 65～72 px/s，即弹速的 5.4%～6.0%。

因此，当前视觉问题不应被简单归因于“粒子继承了过多弹速”。如果目标规则是“一切拖尾粒子速度不超过弹速的五分之一”，应把它写成显式速度上限，并同时检查沿弹道分段生成粒子所造成的视觉跟随感。

## 2. 推荐数值

### 2.1 井星与玩家

| 参数 | 当前 | 推荐 | 作用 |
|---|---:|---:|---|
| `primary_surface_radius` | 10000 | **10000** | 保持井星尺度 |
| `primary_gravity_acceleration` | 135 | **320** | 提高近地约束与未来升级余量 |
| `jump_speed` | 116 | **178** | 保持约 50 px 的纯跳高度 |
| `boost_acceleration` | 185 | **185** | 推进成为轨迹延长器，而非单独起飞器 |
| `MAX_ENERGY` | 120 | **100** | 与玩法文档基线统一 |
| `BOOST_ENERGY_COST` | 35/s | **35/s** | 满能量连续推进约 2.86 s |
| `GROUND_ENERGY_RECOVERY` | 24/s | **22/s** | 与玩法文档基线统一 |
| `AIR_ENERGY_RECOVERY` | 9/s | **8/s** | 与玩法文档基线统一 |
| `terminal_speed` | 255 | **900** | 仅作数值安全阀，不再主导逃逸平衡 |
| `walk_speed` | 62 | **62** | 不改地面战斗节奏 |

纯跳高度：

\[
h=\frac{v_j^2}{2g_s}
=\frac{178^2}{2\times320}
\approx49.5\text{ px}
\]

因此重力虽然从 135 提高到 320，玩家的基础跳跃高度基本不变；起跳至最高点从约 0.86 s 缩短至约 0.56 s，动作会更紧凑。

### 2.2 逃逸安全余量

新表面逃逸速度：

\[
v_e=\sqrt{2\times320\times10000}
\approx2530\text{ px/s}
\]

最大推进时间：

\[
t_b=\frac{100}{35}\approx2.86\text{ s}
\]

忽略重力损失的保守推进速度增量：

\[
\Delta v_b=185\times2.86\approx529\text{ px/s}
\]

采用“跳跃＋满能量推进＋一枚斥核”的过高估计：

\[
v_{\text{combo}}\lesssim178+529+125=832\text{ px/s}
\]

约为逃逸速度的 32.9%。即使三枚斥核的势能完全叠加，估计上限约 924 px/s，仅为逃逸速度的 36.5%。这还没有扣除飞行期间持续受到的井星重力，因此安全余量足够。

建议冻结以下平衡规则：

> 普通井星初始构筑的极限移动组合不得超过当地逃逸速度的 40%；进入轨道或离星必须依赖专用星种、地维设施、飞船或剧情级世界工程。

### 2.3 可感知的飞行结果

在近地恒定重力近似下：

| 操作 | 预计最高离地高度 | 结果 |
|---|---:|---|
| 仅跳跃 | 约 50 px | 基础移动 |
| 跳跃＋持续推进 | 约 117 px | 明显延长滞空，但不能无限上升 |
| 跳跃＋一枚斥核＋持续推进 | 约 341 px | 强力技巧移动，仍会回落 |
| 跳跃＋三枚近似重叠斥核＋持续推进 | 约 578 px | 极端资源组合，仍无法进入轨道 |

在约 3150 px 高度之前，井星重力仍大于 185 px/s² 的基础推进加速度。当前组合远达不到该高度。

## 3. 弹道联动调整

提高全局重力后，不能保留弹体 `projectile_gravity_scale = 3.0`，否则高速幼种下坠会被同步放大约 2.37 倍。

推荐：

| 参数 | 当前 | 推荐 |
|---|---:|---:|
| `projectile_speed` | 1200 | **1200** |
| `projectile_lifetime` | 0.55 | **0.55** |
| `projectile_gravity_scale` | 3.0 | **1.30** |

新的弹体有效重力：

\[
g_p=320\times1.30=416\text{ px/s}^2
\]

与当前 `135×3.0=405 px/s²` 基本相同，因此只提高玩家与世界的重力约束，不破坏已经调出的枪械弹道。

水平射击近似下：

| 水平距离 | 飞行时间 | 下坠 |
|---:|---:|---:|
| 160 px | 0.133 s | 3.7 px |
| 320 px | 0.267 s | 14.8 px |
| 480 px | 0.400 s | 33.3 px |
| 640 px | 0.533 s | 59.2 px |

这能保证近距离仍接近直射，中远距离能够清楚观察到下坠。

## 4. 拖尾粒子规则

### 4.1 速度规则

将“五分之一”定义为绝对上限：

```text
trail_particle_speed <= projectile_speed × 0.20
```

推荐默认分解：

```text
纵向速度 = projectile_velocity × 0.18
横向扰动 = projectile_speed × ±0.035
最终速度 = clamp_length(上述合速度, projectile_speed × 0.20)
```

1200 px/s 弹体对应：

- 默认粒子纵向速度：216 px/s；
- 横向扰动：约 ±42 px/s；
- 最终速度上限：240 px/s。

子弹飞行 0.1 s 可前进约 120 px，而粒子最多前进约 24 px，拖尾会明显留在后方。

### 4.2 生成与寿命

| 参数 | 推荐 |
|---|---:|
| 粒子速度上限 | 弹速 × 0.20 |
| 平均速度 | 弹速 × 0.17～0.19 |
| 生成间距 | 每 8～10 px 一粒 |
| 单粒寿命 | 0.12～0.16 s |
| 横向摆动 | 不超过弹速 × 0.04 |
| 粒子重力倍率 | 与弹体相同，1.30 |
| 每枚弹体可见粒子上限 | 18～24 |

粒子生成后必须使用独立世界坐标更新，不再绑定弹体。沿单帧运动线段补点只能用于填补高速弹体的采样间隙，不能让旧粒子继续跟随新的弹体位置。

## 6. Gate 验收

### Gate G1：基础跳跃

- 峰值高度：45～55 px；
- 起跳至最高点：0.50～0.62 s；
- 不推进时必须可靠回到地面。

### Gate G2：推进职责

- 地面只按推进键不能直接离地；
- 跳跃后推进能显著延长滞空；
- 满能量持续推进不能形成悬停或无限上升；
- 跳跃＋推进预计峰值：100～130 px。

### Gate G3：斥核极限组合

- 跳跃＋一枚斥核＋满推进峰值：300～380 px；
- 三枚重叠斥核极端测试峰值：不超过 650 px；
- 极端测试必须在 5 s 左右重新接触地表；
- 无专用离星设施时，玩家总机械能不得达到零能轨道或逃逸状态。

### Gate B1：弹道

- 320 px 水平距离下坠：12～18 px；
- 近距离 160 px 下坠不超过 5 px；
- 弹体不能因提高世界重力而恢复成慢速抛物体手感。

### Gate V1：拖尾

- 任意拖尾粒子初速度不超过弹体速度的 20%；
- 0.1 s 后，粒子相对弹体明显落后；
- 粒子停止生成后不再随弹体移动；
- 连射 10 s 不超过粒子池上限，不出现整条尾迹同步平移。

## 7. 结论

本轮不应只把 `primary_gravity_acceleration` 单独调大。重力、跳跃、推进、弹体重力倍率和粒子表现必须联动：

1. 井星表面重力提高至 **320 px/s²**；
2. 跳跃速度提高至 **178 px/s**，保持约 50 px 跳高；
3. 推进保持 **185 px/s²**，从“持续上升器”改为“轨迹修正器”；
4. 玩家速度硬上限提高至 **900 px/s**，让物理平衡而非低速截断负责防逃逸；
5. 弹体重力倍率降至 **1.30**，维持现有可读弹道；
6. 拖尾粒子速度显式限制在弹速的 **1/5**，并保证生成后独立运动。
