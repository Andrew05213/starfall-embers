## 3. 已完成的设计工作

### 3.1 世界观与主线

- 冻结核心句：万物由可模拟律尘构成，物质会下坠、反应并保留曾经的状态。
- 初炉、四百多年前主动关炉、宇宙降温、玩家为未完成丹胎等主线骨架已闭合。
- 玩家死亡采用回响棺的近邻接续与跨周目接续，不确认灵魂连续性。
- 五枚见证被定义为“五个有效世界主体对五种不同主法则的证词”，不是五把普通钥匙。
- 坠核、法则见证、地方核心、人造坠核、人造律印、引核的层级已明确区分。
- 四大势力的合理性与缺陷、六种结局以及“不设无代价真结局”已冻结。
- 八颗祖星、开放篇章模板、跨周目变体、任务编排和信息保底规则已有完整草案。

### 3.2 井星篇

- 四条离星路线已闭合：修复旧船、借上升兽、拔取坠核、重启古发射井。
- 拔核后为 11 分 40 秒世界时间崩塌；只能小规模救援，并必须有人留守校正最后的下方。
- 井星空间结构、主要区域、材料、生态、建筑、NPC 与外围地点已补全。
- 井星半径的当前原型基线为 `10000 px`。
- 井星见证属于“重力与方向”；见证不等于坠核。

### 3.3 核心玩法 V0.2

玩法已从“物理投掷物配方”重构为：

```text
动作射击主干
→ 星铸执行语言
→ 真实物质、局部重力与环境反应
```

冻结/暂定冻结的关键方向：

- 空场连续射击本身必须好玩，不能依赖复杂反应救手感。
- 高速幼种、活性成种、天体化星种是同一星种的连续时间尺度。
- 星铸器采用从左到右的星序执行模型。
- 组件角色包括载荷、修饰、调度、触发、作用域和控制。
- 构筑优先改变行为，而不是只做伤害百分比。
- 环境改变并强化构筑，但不决定基础攻击能否启动。
- 不设人物等级和经验值；成长来自规则理解、组件、物质、飞船与见证。

原型路线已经定义为：

```text
移动与重力镜头
→ 基础射击爽感
→ 四种射击骨架
→ 星序执行与编辑
→ 物质反应接入
→ 失稳、自伤与原因链
→ 敌人、星球和长期系统扩展
```

### 3.4 井星数值补丁

当前设计基线：

| 参数 | 基线 |
|---|---:|
| 井星半径 | 10000 px |
| 表面重力 | 320 px/s² |
| 跳跃速度 | 178 px/s |
| 推进加速度 | 185 px/s² |
| 推进能量 | 100 |
| 玩家速度安全上限 | 900 px/s |
| 高速幼种速度 | 1200 px/s |
| 高速幼种寿命 | 0.55 s |
| 弹体重力倍率 | 1.30 |
| 拖尾粒子速度上限 | 弹速的 20% |

设计目标是：斥核＋跳跃＋推进的初始极端组合仍低于逃逸速度的 40%，离星必须依靠专用构筑、设施、飞船或世界工程；提高世界重力时通过降低弹体重力倍率保持现有弹道手感。

## 6. 当前未完成与风险

### 6.1 技术

- C++ 仍是影子模拟，没有成为权威来源。
- 用户本机在 MSVC 修复后尚未回报一次完整的“干净重编＋Godot 启动”结果。
- Windows/Godot 首次编译完整 `godot-cpp` 仍较慢；缓存与并行策略可继续优化，但不应优先于正确性。
- 不应在 GDScript 与 C++ 双方继续复制大量新功能，否则迁移成本会快速增加。

### 6.2 玩法

- 四种射击骨架（连射、霰射、蓄力、流束）尚未完整实现与对比验收。
- 约 18 个首批组件、四种框架、星序作用域/触发/嵌套尚未实现。
- 水、铁砂、油、温度、电荷和局部重力的首轮物质接入尚未实现。
- 失稳、泄漏、自伤和死亡原因链尚未实现。
- 敌人、Boss、完整井星关卡、飞船、经济和长期成长不是当前优先项。

### 6.3 美术

- 三张新背景不是可直接使用的双轴无缝 tile。
- V0.2 角色与生物主要是比例/轮廓概念，不是完整动画资产。
- AI 生成像素图仍需严格像素网格、透明底、色板、轮廓和碰撞生产化处理。
- 大型 Boss 允许达到约 300×200 px，但这只是规模方向，尚无正式 Boss 资产。

### 6.4 叙事

- V0.6 的一致性审查报告缺失。
- 天秤来源、前代丹胎状态、人造见证资格和分炉最低条件仍属待主创确认。
- 井星结构已闭合，不应在当前阶段重新改写。
- 第二颗祖星的完整文本包尚未制作；文档建议优先用倒悬星·萨迦做桌面流程排演。
