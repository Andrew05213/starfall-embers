## 4. 资产状态约定

- **正式基线**：设定、比例或规则已经冻结，后续修改需要升版本并记录原因。
- **概念资产**：可用于确定结构、色板、材质语言和比例，不能直接视为游戏成品。
- **当前候选**：当前希望继续生产化的版本，但仍需通过像素网格、双轴无缝与拼接验收。
- **早期候选**：被新版本替代，或未纳入当前编号体系；只保留作比较与追溯。
- **旧概念资产**：已明确不适合作为正式大地图背景，但仍有构图与区域辨识参考价值。

## 5. 当前最重要的限制

- 井星篇四条离星路线已经闭合，不重新改写结构。
- 常规人物按约 20 原生像素高处理，不提高回 50 px。
- 井星当前原型半径为 10,000 px；这不是同时激活 3 亿像素模拟的要求。
- 不把坠核、法则见证与引核星种混为同一概念。
- 不把五枚见证简化为五个固定星球钥匙。
- 不用低速硬上限替代重力和逃逸速度平衡。
- 拖尾粒子生成后独立更新，初速度不超过弹速的 20%。
- 地质背景按区域和地质环境组织；一张 1254×1254 图不能拉伸成整颗井星背景。
- `素材/地质背景/当前候选/` 中的图片目前均未通过严格双轴无缝验收，不得直接接入正式场景。
