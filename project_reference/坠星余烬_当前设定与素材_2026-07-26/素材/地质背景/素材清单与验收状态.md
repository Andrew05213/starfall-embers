# 井星地质背景素材清单与验收状态

## 1. 结论

当前编号体系共有 **9 张候选**：八类基础地质环境，加一张井壁陶岩第二变体。

这些图片在视觉上可以进行四向重复预览，但尚未满足“像素级严格四向无缝”的生产要求。对边逐像素比较时，每张图都有大量不一致像素；严格无缝要求左右和上下差异都为 `0`。

它们也保留了较高的颜色数量，属于 AI 生成的像素风候选，而不是已经完成调色板归一、像素网格重建的最终游戏资产。

## 4. 正式接入前的验收门

每张当前候选必须逐张完成：

1. **像素网格重建**：消除仿像素噪声、亚像素边缘和过量近似色。
2. **调色板收敛**：为同一地质环境建立明确色板；不能仅依赖 AI 生成时的视觉近似。
3. **双轴严格无缝**：左边界逐像素等于右边界，上边界逐像素等于下边界。
4. **2×2 与 3×3 拼接检查**：除接缝外，还要排查十字节点、棋盘节奏、对称万花筒和长距离重复。
5. **语义分层**：背景中的水痕、热蚀、菌丝和矿痂不得被误认成可交互物质。
6. **区域变体**：高覆盖地质环境至少准备 2～4 个可互换循环变体。
7. **引擎导入检查**：关闭滤镜和 mipmap，使用 nearest 采样，确认相机移动和缩放不产生采样缝。

通过以上验收前，这些图片不得进入正式场景、碰撞层或物质模拟层。
