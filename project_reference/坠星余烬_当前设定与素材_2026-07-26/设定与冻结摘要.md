# 《坠星余烬》设定与冻结摘要

本文件只做导航和状态汇总，不替代正文。出现冲突时以 `文档/00_阅读说明与冻结基线.md` 为最高优先级。

## 1. 项目核心

《坠星余烬》是一款以“星铸编程语言 × 射击手感 × 真实质量 × 局部重力 × 物质反应”为核心的像素沙盒动作游戏。

宇宙中的万物由可模拟的“律尘”构成。物质会下坠、反应、破坏、沉积，并保留曾经发生过的状态。玩家从井星的回响棺醒来，通过星种构筑、环境改造、战斗和航行接触不同世界，最终面对是否重启初炉以及谁有资格替世界作证的问题。

## 2. 世界观冻结项

- 成熟星体依靠坠核维持自己的坠律与“下方”，重力不是全宇宙统一背景。
- 初炉曾参与多轮炉世；四百多年前的关炉与见证制度构成当前宇宙秩序的历史根部。
- 玩家没有可靠身份记录。回响棺可维持两级连续性，但身体究竟被生成、转移还是以两种过程重合，保持未知。
- 坠核、法则见证与引核星种属于不同层级。
- 八类基本见证为：热与燃烧、流动与压力、重力与方向、光与传递、生命与同化、电荷与意识、状态与时间痕迹、质量与交换。
- 井星见证属于“重力与方向”。同类证词可以并存，但通常只占一个开炉类别。
- 四大势力均保留自身的合理性与缺陷；不设无代价真结局。
- 小规模救援可以改变具体生命的命运，但不能洗去大规模毁灭。

## 3. 井星篇冻结项

- 井星篇结构已经闭合，后续只做生产化修订。
- 四条离星路线：
  1. 修复旧船；
  2. 借上升兽离开；
  3. 拔取坠核并承担后果；
  4. 重启古发射井。
- 三名主要角色为砾、简七、照临；路线同行倾向存在，但不是硬锁定。
- 人物标准高度约 20 px。
- 井星当前原型半径为 10,000 px；地理设计可用约 10k 的口径描述。
- 星体内部由矿井、空腔、断层、遗迹、聚落和生态区组成，不是均匀填满的实心圆。
- 背景应像《Noita》《泰拉瑞亚》一样承担位置辨识；不同地质环境和遗迹区域使用不同视觉语汇。

## 4. 当前玩法基线

- 空场射击本身必须好玩；普通战斗先允许射击，再奖励玩家理解物质与环境。
- 星种是连续成长状态，星铸器执行的是可组合的行为程序，而非单纯配方。
- 环境负责让同一构筑产生变异，不负责把基础战斗变成准入门槛。
- 镜头平滑跟随主要重力方向，使玩家当前“下方”逐渐落到屏幕下方。
- 敌人按身体结构、材料和行为设计；Boss 才要求更强的地形、材料、重力和星序协同解法。
- 当前开发顺序仍是移动与重力镜头、射击主干、四种射击骨架、星铸执行语言、物质接入，而不是优先扩展完整井星关卡、Boss、飞船和经济。

## 5. 井星数值基线

| 参数 | 当前基线 |
|---|---:|
| 井星原型半径 | 10,000 px |
| 表面重力 | 320 px/s² |
| 玩家能量上限 | 100 |
| 地面能量恢复 | 22/s |
| 空中能量恢复 | 8/s |
| 弹体重力倍率 | 1.30 |
| 拖尾粒子速度上限 | 弹速的 20% |

平衡目标：

- 常规“斥核＋跳跃＋推进”极端组合仍低于当地逃逸速度的 40%。
- 离星依靠专用星种、地维设施、飞船或世界工程，而不是初始移动组合。
- 提高世界重力时，通过降低弹体重力倍率维持高速幼种的现有弹道手感。
- 拖尾粒子生成后独立运动，明显滞后于弹体。

## 6. 视觉资产基线

井星 V0.3 设定集包含 22 张拆分概念资产：

- 3 名角色：砾、简七、照临；
- 3 种生物：上升兽、沉浆鳗、钉足兽；
- 8 个物品与材料；
- 8 个环境与建筑概念单元。

人物、生物与物品的比例已经按约 20 px 人物基准重建；环境概念单元为 160×90 原生像素，只冻结结构、色板和材质语言，不是正式关卡背景。

当前地质背景共 9 张候选：八类基础地质环境，加一张井壁陶岩循环变体。它们具备一致的暗色像素视觉语言，但仍属于生产化前候选，详见 `素材/地质背景/素材清单与验收状态.md`。
