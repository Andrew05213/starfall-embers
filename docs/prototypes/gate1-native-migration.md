# Gate 1.5：原生模拟迁移

## 目标

在不改变 Gate 1 已通过的移动、瞄准、枪感和表现参数的前提下，把高频、确定性的战斗状态逐步迁移到独立 C++20 `sim_core`。迁移期间 Godot 仍负责输入、场景、镜头、音频、粒子和渲染。

## 第一批切片

当前原生切片包含：

- 30 Hz 固定步高速幼种状态更新；
- 井星主坠核的内部均匀球、外部平方反比重力；
- 批量生成、外部退役、状态快照和事件输出；
- 跨多个追赶 tick 累积、显式 drain 的事件队列；
- 前一位置与当前位置，供表现层做渲染插值；
- Gate 1 数值基准和确定性原生测试。

第一批切片不会替换正在运行的 GDScript 战斗场景。地形和目标碰撞仍由现有 Godot 原型处理；弹道权威状态已经通过固定版本的 `godot-cpp` 暴露为批处理接口，但现有场景尚未切换消费者。

## 后续接入顺序

1. 固定 Godot 4.7.1 运行时与 `godot-cpp` 10.0.0-rc1（4.6 API 兼容下限），建立可加载的 GDExtension。（已完成）
2. 桥接一次提交整批生成/退役命令，一次读取整批状态/事件。（已完成）
3. 在同一输入下并行运行 GDScript 与 C++ 弹道，对比位置、速度、寿命和事件。（独立差分与 Combat Lab 真实发射影子均已接入）
4. 将 Godot 视觉节点改为只读取前后两个固定步状态并插值。
5. 定义粗粒度碰撞代理批次，把目标与地形碰撞移入原生核心。
6. 回归通过后删除相应的 GDScript 权威更新逻辑。

## Gate 1 锁定基准

| 参数 | 数值 |
| --- | ---: |
| 固定步 | 30 Hz |
| 井星主坠核中心 | `(320, 10020)` |
| 井星参考半径 | `10000 world px` |
| 地表重力 | `320 world px/s²` |
| 幼种初速 | `1200 world px/s` |
| 幼种寿命 | `0.55 s` |
| 幼种重力倍率 | `1.3` |

这些常量只用于迁移回归。Gate 2 开始后，正式数值应由星序编译结果和内容数据通过生成命令传入，而不是写死在模拟算法中。

## 第一批验收

- 原生核心不包含任何 Godot 类型或头文件；
- 外部重力满足 `g(r)=g_surface×(R/r)²`；
- 内部重力满足 `g(r)=g_surface×(r/R)`；
- 一屏弹道下坠保持在 Gate 1 的 `12–20 world px` 范围；
- 最后一个固定步按剩余寿命截断，不越过 `0.55 s`；
- 批量命令保持确定顺序，相同输入产生相同状态；
- 非法及非有限数值的生成命令被拒绝。
## 真实发射影子检查点

Combat Lab 会把真实的 `juvenile_requested` 发射流同步送入原生 Host，已验收的
GDScript 子弹仍保持权威。后置执行的影子节点负责批量提交生成与退役命令、推进
30 Hz 原生固定步，并按相同弹龄比较位置和速度，避免把 60/30 Hz 调度相位差误判
为模拟漂移。寿命结束和命中退役事件也通过 request ID 关联。未安装可选
GDExtension 时影子层会自动停用，但 CI 构建要求其必须启用并产生真实比较样本。
