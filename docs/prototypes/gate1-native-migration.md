# Gate 1.5：原生模拟迁移

## 目标

在不改变 Gate 1 已通过的移动、瞄准、枪感和表现参数的前提下，把高频、确定性的战斗状态逐步迁移到独立 C++20 `sim_core`。迁移期间 Godot 仍负责输入、场景、镜头、音频、粒子和渲染。

## 第一批切片

当前原生切片包含：

- 30 Hz 固定步高速幼种状态更新；
- 井星主坠核的内部均匀球、外部平方反比重力；
- 批量生成、外部退役、碰撞快照、状态快照和事件输出；
- 跨多个追赶 tick 累积、显式 drain 的事件队列；
- 前一位置与当前位置，供表现层做渲染插值；
- Gate 1 数值基准和确定性原生测试。

Combat Lab 现已默认请求 C++ 权威弹道。GDScript 实现仍作为明确回退模式保留，不因影子对比通过而删除。

## 后续接入顺序

1. 固定 Godot 4.7.1 运行时与 `godot-cpp` 10.0.0-rc1（4.6 API 兼容下限），建立可加载的 GDExtension。（已完成）
2. 桥接一次提交整批生成/退役命令，一次读取整批状态/事件。（已完成）
3. 在同一输入下并行运行 GDScript 与 C++ 弹道，对比位置、速度、寿命和事件。（独立差分与 Combat Lab 真实发射影子均已接入）
4. 将 Godot 视觉节点改为只读取前后两个固定步状态并插值。（已完成）
5. 定义粗粒度碰撞代理批次，把目标与地形碰撞移入原生核心。（已完成）
6. 保留可独立运行的 GDScript 回退，并以显式模式切换控制唯一权威源。（已完成）

## Gate 1 锁定基准

| 参数 | 数值 |
| --- | ---: |
| 固定步 | 30 Hz |
| 井星主坠核中心 | `(320, 10020)` |
| 井星参考半径 | `10000 world px` |
| 地表重力 | `320 world px/s²` |
| 幼种初速 | `1200 world px/s` |
| 幼种寿命 | `0.55 s` |
| 幼种重力倍率 | `1.3` |

这些常量只用于迁移回归。Gate 2 开始后，正式数值应由星序编译结果和内容数据通过生成命令传入，而不是写死在模拟算法中。

## 第一批验收

- 原生核心不包含任何 Godot 类型或头文件；
- 外部重力满足 `g(r)=g_surface×(R/r)²`；
- 内部重力满足 `g(r)=g_surface×(r/R)`；
- 一屏弹道下坠保持在 Gate 1 的 `12–20 world px` 范围；
- 最后一个固定步按剩余寿命截断，不越过 `0.55 s`；
- 批量命令保持确定顺序，相同输入产生相同状态；
- 非法及非有限数值的生成命令被拒绝。
## 三种运行模式

- `gdscript_fallback`：不向 Native 注册弹体，现有 60 Hz GDScript 推进和碰撞独立运行。
- `native_shadow`：GDScript 继续权威，Native 只比较轨迹、寿命与退役，不触发玩法副作用。
- `native_authoritative`：Native 决定推进、寿命、实体/地形命中、销毁和事件顺序；Godot
  只更新插值视觉并把命中事件转换为一次伤害、反馈和统计。

随机种子在配置 Host 时显式传入。暂停不会推进 Native tick，重置会替换 Host 并清空命令、
状态和未消费事件。

## 固定步基准

`starfall_native_ballistics_benchmark` 固定使用 160×90（14,400 cell）地形快照、4 个目标代理、
120 个 tick、每 tick 256 条生成命令，共 30,720 条命令。2026-07-31 Windows Release 本机结果为
峰值 4,096 个活动弹体、约 5.95 ms/tick。该数字是迁移基线，不是跨机器性能承诺；后续改变
碰撞批协议时必须以相同负载对比并解释退化。

## 真实发射影子检查点

Combat Lab 会把真实的 `juvenile_requested` 发射流同步送入原生 Host，已验收的
在 `native_shadow` 模式下，GDScript 子弹保持权威。后置执行的运行时节点负责批量提交生成与退役命令、推进
30 Hz 原生固定步，并按相同弹龄比较位置和速度，避免把 60/30 Hz 调度相位差误判
为模拟漂移。寿命结束和命中退役事件也通过 request ID 关联。未安装可选
GDExtension 时影子层会自动停用，但 CI 构建要求其必须启用并产生真实比较样本。
