# ADR-0001：Godot 表现层与独立模拟核心

- 状态：已接受
- 日期：2026-07-16

## 背景

项目需要 Godot 的成熟编辑器和跨平台表现能力，也需要对大规模像素物质、重力与星种执行进行数据导向优化和独立性能测试。

## 决策

采用 Godot Standard 作为表现层（具体版本政策见 ADR-0002）；权威模拟放在不依赖 Godot 的 C++20 `sim_core`；两者通过官方 `godot-cpp` GDExtension 批量通信。

Godot 拥有场景、输入、UI、音频和渲染。`sim_core` 拥有物质状态、反应、重力、星种逻辑、确定性步进与可持久化模拟状态。桥接层只负责类型转换、生命周期和批传输。

## 后果

- 模拟可以脱离图形环境运行测试、模糊测试和性能基准。
- 需要维护明确的批数据协议和版本。
- 表现层不能直接修改权威像素状态。
- GDExtension ABI、平台产物和 `godot-cpp` 版本必须固定并在 CI 验证。
