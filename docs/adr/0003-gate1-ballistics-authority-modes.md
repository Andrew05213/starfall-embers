# ADR-0003：Gate 1 弹道权威模式切换

- 状态：已接受
- 日期：2026-07-31

## 背景

Gate 1 已验收的 GDScript 弹道必须迁移到 `sim_core`，但影子结果一致并不足以证明可以安全
删除回退路径。迁移期间若 Godot 与 C++ 同时产生命中、伤害或反馈，还会造成重复副作用。

## 决策

Combat Lab 提供 `gdscript_fallback`、`native_shadow` 和 `native_authoritative` 三种显式模式。
权威模式中，C++ 以固定 30 Hz、显式 seed 和稳定 ID 顺序决定弹体推进、寿命、目标/地形命中、
销毁及事件顺序。Godot 每个固定步批量提交目标代理与完整地形网格，批量读取前后状态和事件，
并以 60 Hz 插值表现；不得逐弹体、逐目标或逐像素跨越 GDExtension 边界。

Shadow 模式的 Native 结果只用于诊断，不触发伤害、音效或统计。Fallback 模式不向 Native
注册弹体，继续独立运行现有 GDScript。扩展不可用时自动进入 fallback。

## 后果

- 同一时刻只有一个玩法权威源，命中副作用只执行一次。
- GDScript 回退必须持续通过回归，直到后续 ADR 明确允许移除。
- 碰撞网格批次会增加每个固定步的传输量，后续区块迁移应改为版本化脏区批，而不是改变
  当前逐像素禁令。
- 暂停冻结权威 tick；重启边界重建 Host 并丢弃活动弹体、排队命令和未消费事件。
