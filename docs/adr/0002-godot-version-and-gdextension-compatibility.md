# ADR-0002：Godot 版本与 GDExtension 兼容基线

- 状态：已接受
- 日期：2026-07-19

## 背景

项目原先把尚不存在的 `4.7.1-stable` 写进了文档与 CI，因而无法形成可复现的下载、构建和 ABI 验证链。当前官方稳定维护版本为 Godot 4.6.3，而 `godot-cpp` 10 的 API 生成器支持 4.3 至 4.6。

## 决策

- 编辑器、无头测试与发布基线固定为 Godot 4.6.3 Standard。
- `third_party/godot-cpp` 固定为 `10.0.0-rc1`，Git 提交 `58d1de720b8ffe9f8ffcdfe3a85148582cfd2e74`。
- GDExtension 使用 Godot 4.6 API 生成，扩展描述符的最低兼容版本为 4.6。
- Godot 4.7 发布稳定版后，单独进行兼容测试并形成新的 ADR；在此之前不追逐预发布引擎。
- CI 必须先构建桥接动态库，再启动 Godot 导入与原生桥冒烟测试。

## 结果

依赖可复现，Godot 与 C++ 边界能够在 CI 中真实加载验证。代价是暂不使用 4.7 预发布功能，并且桥接构建时间增加。
