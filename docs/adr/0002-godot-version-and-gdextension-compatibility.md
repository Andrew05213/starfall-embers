# ADR-0002：Godot 版本与 GDExtension 兼容基线

- 状态：已接受
- 日期：2026-07-19

## 背景

迁移初稿曾因当时的版本判断把运行基线降到 Godot 4.6.3。当前官方稳定维护版本已是 Godot 4.7.1；同时，`godot-cpp` 10.0.0-rc1 提供稳定的 Godot 4.6 API 生成基线，可作为扩展的最低兼容层。

## 决策

- 编辑器、无头测试与发布基线固定为 Godot 4.7.1 Standard。
- `third_party/godot-cpp` 固定为 `10.0.0-rc1`，Git 提交 `58d1de720b8ffe9f8ffcdfe3a85148582cfd2e74`。
- GDExtension 使用 Godot 4.6 API 生成，扩展描述符的最低兼容版本为 4.6。
- 运行时使用 Godot 4.7.1，但不把扩展 API 下限同步抬高；后续只有在确实需要 4.7 专属扩展 API 时才升级 `godot-cpp` 生成基线。
- CI 必须先构建桥接动态库，再启动 Godot 导入与原生桥冒烟测试。

## 结果

依赖可复现，Godot 与 C++ 边界能够在 CI 中真实加载验证；扩展保持对 4.6 API 的兼容，同时项目使用当前 4.7.1 稳定运行时。代价是桥接首次构建时间增加。
